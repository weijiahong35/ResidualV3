使用 `researchwrite` 的研究基础、证据表、论证与执行契约流程。本任务是给执行 chat 的阶段性交接，相关基础集中在 `RESEARCH_BASIS_CN.md`，不扩展成论文正文或完整科研申请书。两名协作审查者分别检查理论识别/统计和自主执行/资源边界；角色分工不代表错误独立，也不构成外部同行评议。

## 已采纳的实质修订

| 问题 | 修订 | 仍然存在的限制 |
|---|---|---|
| 同状态 raw/head 改善不能证明利用条件信息 | 增加同 C/i 分支间前驱置换，保持前驱边缘频率；正确、置换和 raw 风险全部报告；首位置负对照 | 置换可能改变联合输入分布；不估算整体收益的因果份额 |
| “可预测”缺独立预测任务 | 主问题收窄为现有头能否利用/修复；留出预测探针列为可选 | 未跑探针就不声称可部署预测 |
| 上下文来自某方法会引入比较臂选择 | A/B 使用独立 target 轨迹和事先规定锚点 | 仍只代表该上下文与前缀测度 |
| 有限分支经验分解易被误称总体互信息 | 明确 K 敏感性、经验/总体区别与 EOS 存活测度 | 总体估计精度由 pilot 与区间决定 |
| 单分支成对 TV 未定义 | n<2 记缺失；n=1 的零经验 KL 分量标退化 | 不借样本退化宣称条件变化很小 |
| 概率乘积可能重复计入真实接受事件 | G 仅含 proposal 路径终止/预算条件；实际 reached 单列 | terminal/bonus 实现必须由 pilot 核验 |
| 事后筛选无终止轮可能破坏公式 | 删除无条件套用，使用预先定义合成检查与完整终止记录 | 不承诺所有 runtime 日志 AC 都等于实际输出/轮 |
| 预算仅限制新增作业，可能放任在途超额 | 累计所有支路预算，预留保存时间，到限停止自有作业；写盘前检查 | 24 GPU 小时不保证足够完成全部支路 |
| 原 CPU 收尾准入规则不一致 | 控制器、子任务/重试及收尾均需确认终态和预约释放；失败终态可如实缺审计 | 无法核验时继续 CPU 工作，不接管原任务 |
