# 数学合同：规定参考修正的最小幅度

以下推导是标准概率/线性代数工具，不声明新定理。实验新增对象是：不同来源的固定方向，在真实折外失配上对同一参考动作的代价差。

## 1. 唯一分析动作族

p、q为FP64全词表合法分布，分别由已存BF16 target/J logits稳定softmax得到。S为raw J的Top256，按概率降序、并列最小token ID。T为其补集。

W为BF16静态权重精确解码为FP64，B为FP64行正交方向。A=W_S Bᵀ。对系数a，仅S内加δ=Aa，S外logits保持原值，然后全词表归一化，得到q_B(a)。h为存档J_hidden解码值。

主预算 ||a||₂≤.8 max(||h||₂,1e−6)。正交B使||a||等于对应hidden位移范数；词表候选mask之后的概率变化仍依赖W、q和S。这里是FP64闭球容量参照。头的sigmoid剂量实际处于开区间，闭球边界不能直接称头可精确输出；数值判定另留1e−6 dose余量。

具体头映射为`a=.8*sigmoid(z)*max(||h||₂,1e−6)*u/max(||u||₂,1e−6)`，u=0时a=0；eps和源码见[头合同](protocol/HEAD_CONTRACT_CN.md)。开区间是实数公式性质，FP32 sigmoid可饱和到端点，执行时检查实际系数范数并记舍入误差，不能据此把闭包oracle当训练可实现性证明。oracle还使用了每状态p，而头的固定输入未必能区分多个H；逐状态可行不保证存在一个同时实现这些动作的头。

不得把原BF16投影/加法的动作集与此闭球相等；不得称全词表(p−q)W就是掩码动作梯度。后者的KL系数梯度在a=0为 B W_Sᵀ(q_S−p_S)。

## 2. 所有臂共享的参考概率路径

记p_T=Σ_T p_v、q_T=Σ_T q_v，直接对尾部求和，不用1−候选和消减精度。定义

```
p_tilde_v = p_v                    v∈S
p_tilde_v = p_T * q_v/q_T          v∈T
r(t)      = (1−t)q + t p_tilde     t∈{.25,.5,1}
```

候选内向target移动，尾部只改总质量、保留q的条件形状。r(t)为合法完整分布，但p_tilde未必是允许动作族的TV最优点。

对0≤s≤t≤1，令a_S=Σ_S|p_v−q_v|，由尾部L1的Lipschitz界：

```
TV(p,r(t))−TV(p,r(s))
 ≤ −(t−s)/2 * [a_S−|p_T−q_T|] ≤ 0.
```

这是路径定义保证的相对raw安全性。报告其改善只用于规定公共任务难度；不能用“路径安全/改善稳定”支持E空间来源。

当p_T或q_T为0、log概率非有限、解码出现非法值时，该记录reference_cost_NA；不要加epsilon或截尾改变目标。所有正常BF16 softmax的极小值用log域处理，必要时用logsumexp求tail；真正下溢与无效分开记账。

## 3. 唯一候选logit位移和最小代价

由于S外logit固定，实现r(t)的候选位移唯一：

```
d_v(t) = log(r_v(t)/q_v) − log(r_T(t)/q_T),  v∈S
A a = d(t)
a_star = A^+ d(t)
kappa_B(t) = ||a_star||₂
cost_B(t) = kappa_B(t) / max(||h||₂,1e−6)
```

若d在A列空间内，a_star是实现该指定分布的最小范数解；若不在，则该指定动作无精确解。该线性命题不涉及“是否还有另一种同样改善TV的动作”。严禁把cost_B(t)写成任意TV降幅的最小代价。

重建r(t)的p完整值对所有臂相同。用A本身的SVD求解，禁止用AAᵀ正规方程替代病态审计；同一C/i的SVD可跨H/t复用。满行秩也只是无幅度约束下的可达，不保证满足.8预算。

## 4. 数值状态与误差保护

- SVD相对截断阈值1e−10；若未达到256满行秩，不据此宣称精确不可达或cost=∞，记numerical_unresolved，保留奇异值、投影残差和已有见证。
- 满行秩时须验证 ||Aa−d||₂≤1e−8 max(1,||d||₂)，重建完整分布TV≤1e−8，且max|BBᵀ−I|≤1e−8。
- 定义保守浮点保护：sigma_low=σ_min−1e−12||A||₂。若≤0记未定。eta=[||Aa−d||₂+1e−12(||A||₂||a||₂+||d||₂)]/sigma_low；记录 `[max(0,||a||−eta),||a||+eta]/max(||h||,1e−6)`。它是本包浮点保护区间，**不是定向舍入或有理数严格证书**。
- 若相对成本保护宽度>1e−4（分母max(kappa,1e−12)），该成本的实质比较未定；保留连续值。没有技术定位不能换solver/阈值重试。
- dose upper<.8−1e−6：budget_feasible；dose lower>.8+1e−6：budget_exceeded_for_reference；其余budget_unresolved_or_closure_boundary。后者不能自动按可行计数。
- 主log成本比用双侧有限正成本；区间最坏界log(cG_low/cE_high)和log(cG_high/cE_low)同时汇总，任何下界为0不加伪计数，保留未定。数值保护不足以支持方向/幅度时不能判阳性。
- 在有限参考集合{raw,r(.25),r(.5),r(1)}上，确定可行项的最大改善是离散集合下界；加入预算未定项后的最大改善是该离散集合的可能上界。两者都不是完整动作族的优化上下界。

把理论上的“精确解”、数据中的“数值可重建”与“原BF16实现可执行”分开。

## 5. 小头训练与完整TV评估

令候选位移δ由FP32小头及FP32 A产生，q固定，Z=q_T+Σ_S q_v expδ_v，则

```
KL(p||q_B)−KL(p||q) = log Z − Σ_S p_v δ_v.
q'_v = q_v expδ_v/Z (S),  q'_v=q_v/Z (T).
```

训练只需q_S、p_S、q_T即可得到精确动作相关KL项；这不是合桶近似。评价TV仍需要全部p_T内部形状：`0.5[Σ_S|p−q'|+Σ_T|p−q/Z|]`，不能用|p_T−q'_T|替换后者。

主科学评价统一：将头输出FP32系数a转FP64，经同一FP64 A和原始BF16解码logits计算完整概率。另在固定工程C上检查训练FP32投影与此参考的TV漂移≤1e−5。超过则技术失败/未定，不能把不同精度的动作混在一张成本表里。这个检查不认证native BF16。

理论单元核验固定为：小词表全分布与候选+tail KL/梯度相等；r(t)安全；SVD最小范数及零空间扰动范数不减；Top256/tail概率重建；近秩亏与预算边界留NA；尺度副合同成本反比关系。只用于数学实现正确性，不作科学阳性证据。
