# 下一项实验：误差提取方向是否具有可复用的修复价值

**比较同一个错误、同一个修正目标：从误差中提取的方向，是否比通用方向需要更小的修正幅度；这种差别能否被同预算小头用起来。**

这是一个固定目标—草稿组合内的探索性来源干预。三个空间为：E（误差）、G（只看输出权重几何，主要对照）、R（随机，辅助）。不能只比较最终平均分；必须同时交付规定动作的最小代价、有限预算下的参考收益、小头实际修复和未判定覆盖。

采用R8已存档的36题、69C，三折按整题隔离。每折24题构造E并拟合头，12题折外评价；跨三折覆盖全部36题。P来源为主，D/F仅作固定外推附表。旧题和旧结果都已暴露，不能称fresh确认，也不声称这些题没参与过主体训练。

此处“复用”限定为方向构造题之外的题目复用；每折训练都包含三域，本轮不检验未见领域迁移。多域结果只描述适用范围。
