## 因果对象

## 标签、输入和参数
- 每条记录 C 为最早 eligible anchor 之前及 anchor 本身的全部 token；anchor<512。精确复用原 eligible_mask，包括 final-block exclusion。随机排列使用 NumPy PCG64 seed 2026101617；64 个不同 group，前32 fit 后32 intervention_eval。
- L=len(C)，target 重放 C+15 个实际 token；teacher logits 取零基 L-1:L+14；标签为这些 logits.argmax，实际 token 仅构成条件。五个 aux 来自 layers[i-1]，i=[2,10,18,26,34]，输入草稿的 aux 严格截到 [:L]。
- 首条样本额外逐 token 重放，比较15位置与 C 内 aux。BF16 SDPA 的完整重放和逐 token 运算形状不同，允许最大 logits 绝对差0.5、平均差0.05且 top1 一致至少14/15；aux 最大差0.5、均差0.05。报告所有值，超限停在工程门禁，不调阈值。完整重放数据是统一两臂的固定 teacher。
- 训练五层主体、fc、hidden_norm、norm、独立 mask embedding；普通 embedding、LM、verifier 模块冻结。初始范数和步范数仅含上述名单；保存名单与尺寸。
- 相同初始化、数据批次顺序、seed、无 dropout；不使用随机增强。两臂32步、batch4，CE 每样本15位置均值，再4样本均值。U 在第t步用 W 第t步对应4样本的每位置均值。
- 每步目标 L2 参数位移=初始名单参数范数×1e-4。逐参数累积 norm、逐参数原位更新，不拼接完整向量，不在GPU留初始副本。测量真实 FP32 位移，允许相对误差1%；零梯度/非有限/任一臂超出匹配容差则停止配对试验，记 partial。

## 固定端点
- 用共同 FP32 干预基线的 detached D-PACE 权重，在32个 eval block 内逐位置按 (weight,groupSHA) 排序；每位置最低8个/最高8个固定。之后训练与bootstrap不改组。
- 每位置在相应固定组内等权求 TV_W−TV_U，再15位置等权平均，为低/高组效应。主端点为低组效应；第二端点为低组减高组。相同5000组重采样索引，PCG64 seed2026101618，整 eval block 成对有放回抽样32个；每位置按该次落入组的抽样次数归一化。某位置组为空，该次bootstrap无效，保留数量；有效不足4900则CI不可判。percentile 1.25%/98.75%双侧区间。
- 两主端点下界均>0且低组点估计>0.005，称此次权重分配有指定方向/幅度的相对因果效应；0.005为操作门槛而非功效保证。必须同时报低组 TV_0−TV_U、TV_0−TV_W；只有 U 比起点改善，才用“修复”；否则用“减轻恶化”。不达门槛不支持这次短程假说，不等于来源绝对不存在。
- 步0/8/32都评估64个block，32为唯一主终点。整组TV、首选欠量、CE、原代理、fit/eval、初始权重离散、初始梯度夹角辅助。CI不包含fit集/训练种子/优化器的不确定性。eval只是本次未更新，不是原模型未见数据。
