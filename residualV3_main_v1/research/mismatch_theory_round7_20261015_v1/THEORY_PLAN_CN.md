# 第七轮研究设计：共同偏差是否对原头收益有实际作用

执行细则见 [EXECUTION_GUIDE_CN.md](EXECUTION_GUIDE_CN.md)，可复制入口见 [START_PROMPT_CN.md](START_PROMPT_CN.md)。

## 1. 要补的证据

**原头的实际概率移动中，是否含有跨历史稳定、并且对完整修复结果具有正边际价值的共同部分？**

R6已支持标签探针在同C/Z的未见历史上平均改善TV；也观察到固定修正会因历史需求改变、调整幅度和跨token补偿而一好一坏。风险/方向预测没有建立可靠优势。这些事实没有自动回答：共同偏差解释是否与原头真正获得的收益相联系。

本轮先定义跨历史共同的预测偏差，再检查它与原头实际动作的交集。原头是固定观察对象，三路输入仅用于确认同一可见条件，不提出新结构，不解释模型的学习过程。

## 2. 三个层次，不能混写

|层次|已有或拟做证据|边界|
|---|---|---|
|有共同可修空间|R5/R6标签参与的共同流探针、R4/R6有限见证|不等于原头实际使用了它|
|原头实际动作中是否含有有用共同部分|本轮固定子动作与移除对照|仅分布层面的诊断，不是训练因果归因|
|该机制能否转化成更好方法与解码收益|本轮不做|不产出新头、gate、AC/TPS或部署结论|

本轮仅分析**同一联合主体的q0→qh**，不能把独立DFlash→联合完整模型的全部正式收益归因于此。

## 3. 从失配中定义保守的共同部分

固定 `C=(上下文、anchor、proposal位置i)`，`H` 为当前位置之前的完整块内历史，`Z` 为原头实际完整输入。目标分布是 `p_H`，并行原始分布为 `q0`，冻结原头输出为 `qh`。同C/Z下q0与qh固定，p_H可随更早历史改变。

只使用该组fit历史，定义每个token都被低估或都被高估的容量：

```text
u(v) = max(0, min_H [p_H(v) − q0(v)])
o(v) = max(0, min_H [q0(v) − p_H(v)])
```

这只识别“逐token方向一致且不越过任何fit目标”的部分。不同token之间相互补偿也可能使整体TV共同改善，因此u/o不是全部可修空间。

现在读取原头已经做出的移动 `d=qh−q0`，取它与上述容量的交集：

```text
a(v) = min(max(d(v),0), u(v))
b(v) = min(max(−d(v),0), o(v))
A = sum a;  B = sum b;  m = min(A,B)
c = m·a/A − m·b/B
```

若m≤1e−12，固定c=0、有效m=0。c称“fit共同支持的原头子动作”；剩余动作 `r=d−c`。这里的m不同于R5/R6探针的 `M_common=min(sum u,sum o)`，不能混用。

比例分配是预先固定的诊断规则，不是最优共同修正。r只表示没有被本规则提取的移动，**不能称为历史特异失配**：它仍可能包含其他共同有益部分、补偿型修正或过量移动。

## 4. 保持总质量的五个分布

令 `t=TV(qh,q0)`，非零时 `ρ=m/t`：

|分布|定义|用途|
|---|---|---|
|q0|原始并行分布|共同参照|
|qh|原头真实分布|完整动作|
|qc|q0+c|单独保留提取的共同部分|
|qr|qh−c=q0+r|从完整动作中移除共同部分|
|qu|q0+(1−ρ)d|均匀移除相同质量的原头移动|

t=0时全部等于q0；m=0时qc=q0、qr=qu=qh。

c与r逐坐标同向、幅度均不超过d，且各自质量和为0，因此qc/qr合法。两种移除都满足 `TV(qh,qr)=TV(qh,qu)=m`，剩余动作大小都是 `t−m`。这些是数学合同，不是待发现的实验效应。

**这些分布是概率诊断，未保证原头的Top256-logit、basis或dose结构可实现。** 分解甚至可能改变尾部内部比例。qu是概率移动的均匀缩减，不是R3的真实头剂量减半；不据此讨论实际修复成本。

## 5. 仅两项主检验

记 `L(q)=TV(p_eval,q)`。所有动作由fit确定并封存后，才读取eval目标。

**H_remove：移除共同部分，会不会损害完整原头的效果？**

```text
η = L(qr) − L(qh)
```

η>0表示该部分在完整动作中有正边际价值；η<0表示移除它反而更好。即使qc在fit上有益，η仍可能为负，例如完整动作已经过量。

**H_specific：在移除同等质量时，这部分是否比均匀移除更重要？**

```text
κ = L(qr) − L(qu)
```

κ>0表示移除共同部分比均匀缩减更损害结果。这个对照排除“只是少改了一些概率质量”的单一解释，不代表已控制所有选择规则或证明唯一机制。

两项必须分别判断。κ为正而η不正，不能称共同部分对完整动作有正贡献；η为正而κ不确定，只支持边际价值，尚未支持超出同质量缩减对照。

主集合固定为：**同一C/i/精确Z的fit子组内部**至少含两种不同完整H，eval匹配该组Z，且完整eval H未出现在该C/i的**任何fit分支（含其他Z组）**。不能跨Z凑两种H。保留m=0的零差状态。seen和全部匹配状态另作描述，不能替换novel主集合。不匹配状态是无定义，不填0。

## 6. 为什么单独有益还可能整体修坏

逐状态计算 `Gc=L(q0)−L(qc)`、`Gr=L(q0)−L(qr)`、`Gh=L(q0)−L(qh)`，保留完整词表token账本。

```text
I = Gh − Gc − Gr
η = Gc + I
```

本分解下I≤0是绝对值几何的性质：同向移动相加后可能越过target，单独收益不能相加。不把“I为负”当新发现，不做第三项主检验，不据Gc/Gh计算“解释了百分之多少”。同测度η均值为正蕴含Gc均值为正，这也是数学关系。

对原头受损状态（Gh<−1e−5）预定描述四类：

1. **Gc<−1e−5：** 提取的共同部分本身未迁移到此历史。再查token方向改变与幅度越界。
2. **Gc>1e−5且η<−1e−5：** 共同部分单独有益，加在剩余动作之上却有害。
3. **Gc>1e−5且η>1e−5：** 共同部分确有帮助，但剩余损伤仍使整体失败。
4. **其他：** 零动作、中性或边界组合，保留而不强行归类。

分类仅描述当前分布与固定分解，不是互斥的训练成因。对每类给总体覆盖与负向幅度，再按固定排序取最多2个真实例子；没有某类就写未观察到。

## 7. 什么会支持或削弱解释

|观察|结论|
|---|---|
|η、κ都获支持|在预定novel集合中，原头实际移动含有具正边际价值的保守共同部分，且优于该同质量对照|
|η支持、κ不支持|该部分对原头有价值，但区别性解释未确认|
|κ支持、η不支持|相对均匀缩减更好，不代表保留该部分优于删去它|
|Gc有益而η非正|共同方向单独有效，但与其他移动叠加后并未形成正边际价值|
|m稀少或覆盖不足|本规则提取的部分不足以承载确认，不推出不存在共同收益|
|未见H上Gc和主量均不支持|这一保守提取规则的迁移与解释未确认，不救跑预测器或换分解|

本轮最多建立**有限分布诊断与原头收益的联系**。公式、概率归一化、数学恒等式、控制通过本身不是创新贡献。真正要观察的是联系是否存在、覆盖多少、在哪些历史上失效。
