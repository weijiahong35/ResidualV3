# 第九轮基础文件核心问题审核

审核对象：`design_support/00_scope.md` 至 `05_style_guide.md`。审核角色：机制解释与反证专家。日期：2026-10-15。

**基础文件审核：通过，可据此起草正式方案。内容充分性评分：8.2/10。** 评分是审稿判断，不是科学证据。本结论不构成正式方案、执行 prompt 或实验启动审核通过；正式文件完成后必须再次审核。

## 对核心问题的对应

1. **形成：** 已将可识别的形成机制限定为同一预测合并了具有不同目标需求的历史，固定完整 p/q，只改变允许区分的历史信息。它能够研究条件信息合并带来的限制，不能识别参数规模、训练数据、优化误差的因果份额。基础文件已明确保留这些未识别来源，没有承诺解释全部失配来源。
2. **什么能修、为什么能修：** 用同一有限真实分布族上的平均改善余量、全部严格改善余量、逐条不恶化时的平均余量，区分“某动作有效”和“存在不伤任何历史的修正”。对象是失配与共享动作的可行性，未改为原头成败预测。
3. **何时失败：** 完整概率单纯形消除了 Top256、basis、剂量等操作限制；只有在这个放宽集合上获得数值证书，才可能把相应有限族的取舍归于信息合并本身。结果允许否定“信息不足迫使损伤”的解释，而非预设该解释成立。
4. **对方法的约束：** 某信息集已存在无损平均改善空间时，不能仅凭当前头损伤宣称信息不足；某种收益幅度在该信息集上被证实必需牺牲分支时，再好的共享头也不能消除此有限族中的取舍。两者都不等于原头已可达、可学或可部署。

## 为什么不是重复旧轮次

- R1 的 KL 账本已研究条件信息和平均拟合项，不能把新风险分解当首次发现条件失配。
- R4 已有共享、安全 oracle 和合法共同动作见证，不能把“一好一坏不等于不可兼顾”再当新发现。
- 本轮允许继续的直接缺口是：**剥离受限操作集合后，哪些取舍仍由有限历史族的信息合并强迫，哪些只是所选修正没有做好。** 真实与同组大小假分组对照进一步检验历史组织性，而非仅利用更多分组参数降低风险。
- R8 全部题面已经暴露。本轮是固定旧数据的机制再分析，不能称 fresh 确认或独立发现。

## 正式稿必须落实的修改

1. **A/M/S 三量缺一不可。** 设 A 为最优平均改善，M 为最优最小逐历史改善，S 为每条历史不恶化约束下的最优平均改善，应验 `0 ≤ M ≤ S ≤ A`。`M≈0` 不等于任何平均改善必伤某条历史；仅当某个平均收益要求超过 S 的认证上界时，才能判断必需付出损伤。至少给出一个 `M=0、S>0` 的数学反例。
2. **信息层级须含完整历史恒等控制 I3。** I0 为全共享，I1 为紧邻前驱，I2 为后两个 token，I3 为完整已观测历史。I3 风险为0是理想全概率集合的合同检查；不是新增实验发现。若同完整历史存档出现不一致 p，先查数值/身份，不以 oracle 强行抹掉不一致。
3. **不得把恒等式当实证结论。** 风险随分组细化不增、A/M/S 的顺序及 pair 闭式均为工具。实证结论应回答哪些真实有限族落入哪种可修复类别，实际历史分组是否比同组大小假分组更能解除相应限制。
4. **不以 pair 代替全 family。** pair 的共同改善证书不推出全部历史可兼顾；全 family 必须有自己的上下界。优化未收敛、上界未闭合均为未判定，不能归入不可修。
5. **损伤解释须注明收益幅度。** 基础表中“若 S 充足则排除此解释”在正式稿应具体化为：若存在所有分支不恶化且达到指定平均收益的见证，就否定“达到该收益必须伤害分支”。`S>0` 只能证明存在某种无损平均改善，未必能保留原头已经获得的全部平均收益。
6. **“没有发现”与“证实不存在”分开。** 若所有认证族均有共同无损空间，可在这些族和认证幅度内排除必需损伤；若仅没找到不可兼顾证书，则只能说未判定。不要将求解未完成、无零值或覆盖不足改写成否定信息限制。
7. **明确科学停止条件。** 有限族证书、分组对照与结论出口做完即收束，阴性同样回答问题；不新增原头预测器、更多探针或重新采样来追求阳性。

## 审核边界

该基础方向能够直接回答其声称的核心子问题，但不能承诺一次解决全部大小模型失配理论。正式方案仍须给出完整概率重构身份、有限规模求解与证书、固定面板、假分组生成、数值容差、资源上限和不同结果的中文判断出口，缺失时不得依据本基础审核直接启动实验。
