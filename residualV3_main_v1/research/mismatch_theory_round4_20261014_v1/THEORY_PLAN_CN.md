# 第四轮研究设计：什么失配能修好，为什么，何时失败

版本：2026-10-14 v1。配套：[执行指引](EXECUTION_GUIDE_CN.md)、[启动 prompt](START_PROMPT_CN.md)。

## 1. 本轮必须回答的中心问题

**研究对象是大小模型的分布失配及其可修复性；冻结 AR 修复头是检验工具。** 本轮完成后，必须能区分：当前修正为什么对某些状态有用、为什么对另一些状态有害、哪些限制来自可见信息或允许的操作、哪些只是当前头尚未做到。不得以重新报告平均 AC、再验证前驱有用、完成采样工程收尾代替这些问题。

问题链与证据合同：

| 问题 | 本轮直接对照 | 允许回答 | 不能偷换成 |
|---|---|---|---|
| 同输入为何一好一坏？ | 核实全部输入与完整输出一致，比较更早历史不同的 target 分布 | 同一冻结修正的后果随未显式区分的历史而变 | 任何共同修正都必然伤害某条分支 |
| 什么失配在允许操作内能修？ | 逐状态放宽最优值、实际操作的可行修正 | 哪些剩余误差由操作边界限制，哪些至少存在可行改善 | 优化器没找到改进就等于不可修 |
| 为什么需要区分分支？ | 各分支分别最优与必须共用一个修正的最优值 | 指定动作集合和有限分支组上的共享代价 | 一般信息论不可约误差、容量鸿沟或唯一原因 |
| 当前损伤是否必要？ | 在“不伤任何观察分支”的约束下寻找共同修正 | 是否存在避免损伤的共同改善，以及达到最优平均值的取舍 | 只看当前坏状态率，或把共同最优自动视为可部署 |
| 当前头还有什么没做到？ | 实际头与满足真实更新约束的共同可行见证 | 已找到的改善空间及其独立分支泛化 | 纯优化误差、必然可学的新头、已完成的方法改进 |

本轮的成败以这些问题回答到哪一层判断。标准不等式、优化成功或新术语不是论文创新；需要新的、可重复的经验解释。

## 2. 出发事实及必须复核的现象

前三轮结果保持：R1正确前驱对应有作用，但条件KL主导未证；R2冻结头的native局部效果和实际每轮接受有支持，尾部几何量的实质解释增量未获支持；R3完整头相对同联合raw每验证轮接受约+0.871，统一半强度平均TV更差约0.0667，不能推荐减半。随机源归因和完整无偏性仍不确定。本轮不重开随机源支路。

上一聊天对 **R3旧dev** 的只读探索按 `(prompt, C, i, previous_token, candidate_hash)` 分组，在i≥2的3736条记录中得到1521组、718个重复组；229个重复组的raw–target TV不同；21组出现full相对raw一正一负，涉及13题。这是探索性、未加权计数，不是新留出结论或发生率估计。

示例：`alpaca_227521df7e4c533d1fe5 / anchor65 / i=7`，分支0与3的前驱均为1495，更早历史不同；full TV收益分别约+0.291657、−0.072615，dose相同。原始出处见执行指引。

**这还没有完成“同输入同输出”数值核验。** 候选hash、相同dose以及代码结构只提供线索。首先重放这些固定C/H，核对hidden、raw logits、q特征、前驱embedding、候选ID/数值、hidden norm、完整q_raw/q_full。无需重新生成旧历史或重复旧主分析。

同C、位置、紧邻前驱相同而更早块内历史不同，按当前proposal索引最早出现在i=3；i=1/2用作身份负控。完全相同历史的重复采样不算“不同历史”现象，但在自然分支权重中保留。

## 3. 信息集、测度与相同输入

固定已验证上下文与anchor C、位置i，主体只计算一次，得到raw状态与q0。令H_j是该位置前的块内历史，p_j为target在(C,H_j)下的完整词表分布。头的可见输入记Z：实际进入头的hidden/q特征、实际前驱embedding及全部配置；当前无soft递推，不把完整H暗中加入Z。

先在同C/i内按前驱token形成候选组，再按实际输入张量核验。不能跨C按“hidden接近”合组；近似一致只能单列，不能套用共同q0/共同q_h定理。若不同token恰好产生相同实际输入，可记录额外合并规则，但锁后不换规则。

本轮主测度为固定target-branch面板：自然T1采样、完整词表、原EOS规则，保留死亡分支/缺anchor/无碰撞题的分母。它不等同native访问分布。所有组内权重来自锁定采样频数，所有外层统计以prompt为单位、三域等权。

定义单状态修复收益 `Δ_j=TV(p_j,q0)−TV(p_j,q_h)`。符号冲突是不同历史的两个分支，一个Δ>ε、另一个Δ<−ε。ε在dev按数值误差确定，不从fresh效果选择。不同p并不意味着无法共同改善；p不同仅意味着同一个q不可能同时精确等于二者。

## 4. 两层修正集合：可认证的参照与真实可行见证

### 4.1 放宽概率集合：可以求可靠边界

S为同一次raw Top256，U为补集，`a=q0(.|U)`。只修改S logits时，U内部条件比例不变。使用闭包：

```text
R = { r : r_S=x≥0, r_U=t·a, t≥0, sum(x)+t=1 }.
```

这是允许S内任意logit修改后的放宽集合；零概率边界可能只能逼近。它放宽了真实basis、dose、有限数值及网络共享参数约束，不能当成当前头可达到的集合。

对一个经核验的同Z组g，分支权重w_j之和为1：

```text
R_ind(g)    = sum_j w_j min_{r_j∈R} TV(p_j,r_j)
R_shared(g) = min_{r∈R} sum_j w_j TV(p_j,r)
L_raw(g)    = sum_j w_j TV(p_j,q0)
L_head(g)   = sum_j w_j TV(p_j,q_h)
```

逐状态最优有闭式值：`R_ind=sum_j w_j p_j(U) TV(p_j(.|U),a)`，边界支持规则沿用R2。`R_shared−R_ind` 是 **该放宽集合、该有限分支组的共享代价**。不能直接称实际失败由缺失历史造成的比例。

共同目标可写成：

```text
0.5 * sum_j w_j [ sum_{v∈S}|x_v−p_jv| + sum_{v∈U}|t*a_v−p_jv| ].
```

核心决策变量只有257个；尾部是关于t的一维凸分段线性函数。可用LP/带分离约束的凸求解，逐坐标处理S，完整计算U的绝对值项。**不能把U压成一个总质量桶**，那会消掉正要研究的尾部差异。大型LP优先用完整尾部函数与切平面/对偶证书，不为每个尾部token永久创建一大批松弛变量。

每组输出完整词表可行目标上界、合法对偶下界、原始约束误差和间隙。固定数值验收目标为TV目标间隙≤1e−6、概率可行误差≤1e−7；仅是求解精度目标，达不到就报告区间/未认证，不放宽到出现理想结论。小词表先用直接LP交叉验证；正文数字要保留求解不确定性。

### 4.2 检查“伤害是否必要”，不是只计算散点相关

同一个R中再解：

```text
R_safe(g) = min_r sum_j w_j TV(p_j,r)
subject to TV(p_j,r) ≤ TV(p_j,q0)  for every observed branch j.
```

raw始终可行。有限数值时显式报告容差，不能把容差内损伤包装成严格零损伤。

- `L_raw−R_safe`给出有限组中可同时不伤害各分支的平均改善空间。
- `R_safe−R_shared`衡量“不伤任何观察分支”相对于最优平均匹配的代价。
- 找到R中的安全共同修正，只能证明放宽集合允许；找到下节真实操作内的安全见证，才支持实际操作可实现替代。
- 认证R_safe几乎等于L_raw，才支持这个有限组没有超过证书误差的安全改善空间；不能用求解失败推出此结论。

安全替代也可能与当前头**平均TV相同**、只是改变损伤分配。如果 `R_safe=R_shared=L_head`，当前头可能已经达到此有限组的最优平均值，仍存在更少伤害的并列最优修正；不能把这一情况叫作平均修复没学好。CPU合同包含这种反例。

这个对照必须覆盖全部合格组，另列原“一好一坏”组；不能只挑容易救回的病例。

### 4.3 真实操作集合：只将可实现的改善当作见证

定义A（即A_ref）为沿当前output basis、S、hidden norm、方向归一化、dose上限及原BF16更新顺序所得logits，经**同一FP64 softmax**产生的参考分布，包含raw关闭修正选项。以下L_head、U_A及最优值均在这个参考概率空间内定义；实际FP32采样分布另报。模型权重冻结；仅为离线诊断优化一个修正向量/剂量，不训练新头或新主体、不用于服务生成。

**先查S对应的输出basis矩阵的秩、奇异值及可实现幅度。** basis rank512而候选数256，不能仅凭“低秩”断言候选内任意方向都受秩限制。浮点连续近似与BF16真实操作分别标记；最终见证必须用原更新算术复算并满足实际约束。

允许固定的小规模优化程序：初始化为raw、当前头、以及一个dev锁定的连续代理解；使用同一固定步数/终止条件。代理KL优化只产生候选，最终按TV评价，不能叫TV最优。所有求解器/初始化/步数在dev锁定，fresh不扩搜索。

令真正共享最优为 `A_shared`，找到的最佳合法见证损失为U_A。保留当前头作为候选，因此在正确数值合同下：

```text
R_ind ≤ R_shared ≤ A_shared ≤ U_A ≤ L_head.
```

`L_head−U_A`是已经找到的可改善量；`L_head−R_shared`只是可能差距的上界。若未找到更好见证，不能说当前头最优或这种失配不可修。实际动作内的安全见证也需检查每条分支约束，不能把只改善平均值的见证叫“救回所有分支”。

可用如下账本组织解释，但不能填造不可识别的项：

```text
L_head = R_ind
       + (R_shared−R_ind)
       + (A_shared−R_shared)
       + (L_head−A_shared).
```

四项依次是放宽操作下剩余失配、有限组共享代价、实际操作额外限制、实际头尚未实现的部分。后两项通常只能给界；最后一项还包含跨组共享网络的表示、训练目标、数据和优化因素，不是纯学习误差。分解依赖集合和先后顺序，不是唯一因果分解。

### 4.4 概率与数值统一

oracle使用从实际BF16 logits构建的FP64参考分布，保持完整支持并记录与实际FP32采样分布的TV差。核验U logits未改后，才使用A_ref属于R的包含关系。对每个**已经评价的**候选可用 `|TV(p32,q32)−TV(p64,q64)| ≤ TV(p32,p64)+TV(q32,q64)` 换算；有限候选或dev测得的最大漂移不是整个未搜索A32集合的统一界，不能据此认证实际FP32空间的全局最优。不能将舍入造成的微小越界当理论反例或偷偷重新归一化掩盖。

头实际输出、目标标签、oracle概率及真实操作见证必须分字段保存。oracle看到了target，不是可部署信息；本轮绝不把它写成新在线gate。

## 5. 从“观察到差异”推进到可反驳的解释

只回归 `gain` 对 `gap` 会利用共有的L_head制造解释力，本轮禁止将其作为理论检验。主证据由以下四部分构成：

1. **身份与覆盖：** 新题上同Z、不同H的覆盖；异号配对率；完整输入与输出parity。覆盖小就限制结论范围，不补采到碰撞足够。
2. **可修复性与共同决策：** 认证的R_ind/R_shared/R_safe及实际操作见证，回答哪种限制存在、哪种替代可行。
3. **独立分支检验：** 同一C的自然分支预分为fit/eval两池。只用fit标签求共同动作，再用于eval中相同Z的分支；每个prompt的所有分支仍同一统计簇。分别报告R中的oracle和A中的实际可行见证。只在eval后求出的最优值是样本内描述，不能冒充fit→eval泛化。
4. **一个固定的修复前结构检验：** 用fit分支的原始残差 `e_j=p_j−q0` 定义同Z组的对向误差质量：对不同历史的每对j,k，计算 `0.5*sum_{e_jv*e_kv<0} min(|e_jv|,|e_kv|)`，再按预定分支对权重平均为C_g。它不使用q_h、Δ或修复后gap。用dev分位点锁定高低组，在新题eval分支上比较异号配对率，并同时报告raw TV、位置、域、候选覆盖和组大小的混杂。若高低组仅是raw误差/组大小不同，不声称新增解释；不可通过新分箱/加特征救结果。

第4项只支持离线解释，target参与的量不是在线特征。默认不再拟合一套新预测头；可用dev锁定的分层/匹配对照，若样本不足则报告覆盖和描述，不以不可用匹配删掉全体主表。

fit/eval未同时出现同Z的组：记录未匹配，不填0、不重新采样。有限组oracle用全部固定分支描述，独立分支测试只用预定可匹配部分，两种分母必须分开。fit至少有两条不同历史才能估计C_g；eval至少有两条不同历史才能定义异号配对率。eval只有一条时可以继续评价fit动作，但冲突率记“不可定义”，不能填0。动作泛化与C_g冲突检验的覆盖、权重和分母分别报告。

为衡量前驱能解释多少条件变化，可以补充同C/i下“所有前驱共用一个R修正”与“按前驱分别共用修正”的最优值差，再与逐历史修正比较。它是嵌套信息参照，不是重新发现前驱有用；有限K低估总体变化的风险仍需说明。

## 6. 必须允许出现的反证

| 观察 | 结论调整 |
|---|---|
| 旧21组不能通过完整输入/输出核验 | 撤回或缩小旧探索现象，先解释身份差异；不得沿错误前提继续讲信息限制 |
| 自然同Z不同H覆盖有限 | 该机制的适用范围有限；不通过强制相同末token制造自然发生率 |
| 大多数合格组的认证共享代价很小 | 不支持把当前失败主要归于缺少更早历史 |
| 实际操作的安全共同见证能改善原坏组且不伤其他分支 | 当前损伤并非这些分支输入碰撞的必然后果，存在当前头未实现的修正 |
| 放宽安全最优仍无超过误差界的改善空间 | 支持该有限组的共同安全修正限制；不外推其他历史或全部模型 |
| 样本内见证好，独立eval分支不稳定 | 暴露有限样本估计/泛化问题，不能宣传可学习或可部署收益 |
| C_g高低组在控制已有因素后没有清楚差异 | 收缩这一具体解释；不扩特征、筛域或回到旧test救结果 |
| 真实操作优化没收敛 | 保留上/下界及“未判定”，不能归为表达受限或信息受限 |

失配类型可以同时受到多种限制；不要强行互斥贴标签，更不要用“实际失败”反过来定义“不可修”。

## 7. 论文能得到什么，仍缺什么

若支持，本轮可以提供：对当前冻结并行draft及修复头，哪些条件变化无法被当前可见信息区别、哪些操作范围允许修复、何种损伤有可行替代，以及这些诊断在新题和独立分支上有多稳定。

这些发现能否构成论文贡献，取决于现象覆盖、效应大小、反证情况及与近邻已有认识的差别。**不能预先保证理论创新。** native连续前缀接受仍是下一层后果；局部oracle改善不是实际rollout、TPS或质量收益。已有native证据保留，本轮的主要时间应花在成败机制上。
