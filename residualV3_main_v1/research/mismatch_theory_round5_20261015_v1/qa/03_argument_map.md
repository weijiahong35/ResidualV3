# 论证与实验草图（先审查，再写主文档）

问题：跨历史共同偏差、前驱条件变化、同可见输入内历史差异分别怎样形成失配，哪些允许共同修正，哪些使固定修正失败？不预设条件项主导。

固定C含上下文/anchor/位置。H为自然target分支历史，Z为完整实际头输入。q0固定，p_H随历史变化。m_C=E p_H，m_Z=E[p_H|Z]。p_H−q0=(m_C−q0)+(m_Z−m_C)+(p_H−m_Z)。经验KL可作三项精确分解；TV不得照搬可加性。权重为固定位置自然存活历史分布，EOS缺失保留。m_C不是假设q0已学到的精确边缘。

E1只作来源描述：真实完整概率、有限K8/16/32预定嵌套敏感性、i1/2负控；三项非容量/因果分解。全样本精确分解与fit→eval均值参考分开；没有重做R1两项主检验。

E2解释共同改善：对fit组，u_v=max(0,min_H(p_H(v)−q0(v)))，o_v=max(0,min_H(q0(v)−p_H(v)))。M=min(sum u,sum o)。r=q0+a u/sum u−a o/sum o，a≤M；fit每支TV改善a是恒等式。全词表概率探针不等于实际basis/dose操作。主检验是固定a=M/2的fit探针在独立eval同Z的TV改善与损伤；M=0时r=q0并计入。另在整个C合并fit作共同基线，但不与不同组大小结果作因果排名。

E3解释条件对应价值：在同C/i内固定8次fit Z标签置乱、保留组大小/target多重集。真实组与置乱组各构造上式方向，每一对用同一a=min(M_real,M_perm)/2；若为0两边都raw并保留。仅fit≥2不同H且eval匹配的Z为主要条件子集，条件由真实组锁定；置乱组即使重复H也不删除。评价同一eval p。先平均8置乱，再prompt聚类。它只检验诊断分组的对应价值，不能宣称语义干预或实际头因果收益。no Z variation的C保留0差。主对照：E2非配对缩步版本对raw、E3等步长真实对置乱，两项分别给97.5%CI，不拼成普遍理论确认。

E4失败解释：固定原头逐token ΔTV账本分方向正确未越界、越界但仍改善、越界致损、反向/原已一致而偏离；正负各排序，尾部也计入。这是事后精确账本，不是预测证据。结合R4已有证书与新状态S/U闭式；新LP可选但默认排除，不要求把每个失败归成唯一原因。M=0不代表无共同修正。

样本：R4旧18 dev及48已暴露题均只能开发/描述；新GSM/HE/Alpaca各12题，共36，K32 fit16/eval16，anchor1/65，固定主位置3/8/15，1/2负控。源面板沿R4，合并所有暴露与专家旧训练清单；新机制留出不等于未参加任何正式评测。fresh前锁所有规则，禁止按结果加样本/改探针；无需新native或训练。

反证：E2不迁移→该类共同fit方向未获迁移支持；E3无优势→未证对应价值，不能说历史无关；C合并与Z同好只说明两种探针均有迁移，组大小/步长不同，不能推出机制等价或充分解释；头损伤有别的合法证据→只排除不可避免，不归因训练；小词表正例/负例/补偿式共益M=0必须覆盖。

审查后补充：i1两个历史项均零，i2仅同Z历史项必须零。8次置乱是固定Monte Carlo对照，不是置乱显著性检验。无合格组的题面是未定义，不填零；合格组的零动作才计零。新LP与native均排除。数学合同已覆盖M=0仍共同改善以及越界但仍改善的反例。
