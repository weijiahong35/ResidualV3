# 第五轮研究包

**这一轮解释失配的结构与修复成败。固定现有模型，不训练新头。**

第四轮知道不少状态存在共同改善空间；这一轮追问：这些空间是不是来自不同历史共同低估/高估的概率质量？真实历史条件对应有什么额外作用？原头具体在哪些概率移动上成功或失败？

## 给执行 chat

直接复制 [START_PROMPT_CN.md](START_PROMPT_CN.md) 分隔线后的全文。执行者将先读：

- [THEORY_PLAN_CN.md](THEORY_PLAN_CN.md)：研究问题、解释与反证，哪些数学结论不能冒充发现。
- [EXECUTION_GUIDE_CN.md](EXECUTION_GUIDE_CN.md)：资料入口、固定实验、样本隔离、统计、共卡预算与完成标准。

## 会做什么

1. 从已有完整分布区分平均预测偏差、可见条件变化、同条件内历史差异。
2. 用一个明确的离线概率操作检查：fit中共同偏差，到了独立分支是否仍能共同纠正。
3. 用等样本数、等调整幅度的置乱对照检查条件对应的价值。
4. 把原头的概率移动与实际收益、损伤及操作限制对照，保留解释不了的部分。

离线概率探针会读取target标签，可能超出现有头的操作范围；它是诊断工具，不是新模型或部署方案。
