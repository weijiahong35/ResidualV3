# Devil's Advocate — Checkpoint 1

结论：**REVISE（完成下列范围与隔离约束后可进入CPU实算）**。本审查只读R2、R6、R7、R8报告及相关源码，没有训练头、运行GPU或修改旧档。

## 要回答的唯一问题

在失配大小、候选覆盖、位置和域相近时，**修复前的共同偏差/历史残差结构是否对冻结原头的实际收益 Gh 有额外解释力**？这是对原头成败的离线解释检验，不是构造另一个平均有效的target探针，也不是上线风险预测器。

## 历史证据已经限制了什么

|证据|已经削弱的具体说法|没有否定的更宽问题|
|---|---|---|

## Critical：把结果换个名字会形成循环

禁止在解释变量中放入qh、Gh、TV(p,qh)、原头逐token TV账本、R7的c/eta/kappa、按原头移动筛出的token或任何以Gh选择的结构阈值。否则“结构解释成功”可能仅重写目标。

允许读修复前p/q0及独立fit分支p来作**target参与的离线诊断**；这与可部署预测严格区分。特征与Gh共享p并不自动构成代数恒等式，但阳性仍不能当作训练因果或无标签事前识别。必须保存白名单、构造入口和封存的特征文件，再单独接入qh算标签。

## 一个可执行的非循环检验

1. 仅用相同C/i/前驱（原完整Z身份需核验）的fit历史计算概率均值 `pbar`；明确是自然频数均值还是去重H均值，固定一种，不选效果更好者。eval完整H按原资格未见；不能让eval p参与pbar。
2. 定义修复前向量 `b = pbar-q0`（fit共同平均偏差）、`r_H = p_H-pbar`（相对该有限fit均值的历史残差）。两者标准分解不是新定理；b不是R5的逐坐标共同安全流，r也不等于容量误差。
3. 固定最多三个标量：`B = 0.5||b||_1`、`R = 0.5||r_H||_1`、`A = <p_H-q0,b>/(||p_H-q0||_2||b||_2)`；零范数单列标记并保留，不删除。这些量不读原头，且不代数决定Gh。若父任务已冻结其他等价低维定义，保留原定义，不因本审查扩网格。
4. 强基线至少保留R2已有D、p(S)、q(S)、position/domain及D²、p(S)²、D×p(S)。同容量固定ridge/低维线性流程，增强版只增加上述结构量。先固定题面隔离、权重、正则和代码，再打开保留档的Gh。旧R6可作开发、旧R7/R8作跨题/跨来源回顾性检验；全部已暴露，不能重命名为新鲜确认集。
5. 主量为每题同状态 `MSE(base)-MSE(structure)`，整题bootstrap；同时报误差、受损比例、共同支持覆盖和按预定TV区间的成败，不以状态条数充当独立样本量。R7 target分支与R8草稿分支分开，不池化换显著性。
6. 理论方向预先写明：在控制D等变量后，更强的共同偏差方向一致性A应关联更高Gh；更大的历史残差R不应自动被假设导致损害，因为它可以沿有益方向变化。三量模型即使提高预测，也只初步支持联合结构解释；不能凭某一系数符号宣布唯一机制。

## 明确的否定/停止规则

- 若跨题保留档的主增量CI跨0：本轮结构增量未确认；不得改A定义、增特征、换子集或阈值重试。
- 若增量上界低于预先锁定的实质门槛（建议开发基线MSE的1%，沿用R2量级规则）：削弱“这套结构具有实质解释力”，不能用tiny positive包装成功。
- 若只在target历史有效而草稿历史失效：主张限于该历史测度，不把后者解释成工程问题。
- 若只在高D子集有效但该子集由结果挑出：仅探索描述，主检验仍按全预定集合判定。
- 若强基线单独已解释且增强模型无增量：不能退回只控制D的弱基线来救结果。
- 即使增量与方向均正，也只能支持固定原头和有限历史库上的离线结构关联；原模型训练成因、真实接受收益和可部署识别仍需另外证据，不能作为本CPU分析的完成标准拖延。

## Major：八轮已暴露数据不是确认性新样本

程序隔离可以防止本轮模型直接训练到保留标签，不能撤销研究者读过前八轮报告后的选题效应。本轮定位应是**直接回答核心问题的回顾性重分析**。阳性给出具体可证伪候选，阴性也应直说当前候选解释不了；不要再次把平均探针收益当主要产出。

## 最强反对意见

“你只是在用target分布的几何摘要预测另一个同样含target的距离，且是在已经分析过多轮的数据上挑出这套摘要；这是否只是度量相关，而不是失配机制？”

应对不是宣称无泄露即有因果，而是提供：修复前特征白名单、fit/eval和题面隔离、强基线增量、有限固定假设、跨来源检验、负结果保留，以及明确的回顾性结论。

## 父任务定案复核（同轮、效果打开前）

父任务实际设计更窄：R7 banks/dev（原R6 fresh48题）拟合，R7 fresh36题及R8 fresh36题F-source作已暴露回顾性测试。主结构仅加 `r = TV(p, μz) / (TV(μz,q0) + TV(p,μz))`；μz是同W fit均值，μ0是同C/i全部fit均值。强基线含D/D²、p/q Top256质量、position/domain、p/q熵，再加TV(p,μ0)、TV(μz,μ0)。**认可该窄设计，不要求采纳上节三个特征候选，更不应扩支路。**

判定：条件PASS，满足以下四项即可实算。

1. r未读qh/Gh，且给定r和基线仍不能代数决定Gh，故是非循环检验；但它只检验“相对历史残差幅度”假说，不检验全部方向结构。高r意味着更难修是经验假说，不是数学定理。
2. 主端点固定为Gh的MSE增量；harm/Brier及TV/覆盖分层高低对比为次要诊断，不从中择优宣布成功。线性概率模型的clip规则对两臂统一且事前固定。
3. 分母0保留并固定r=0及零分母标记；μz/μ0的自然频数或distinctH等权规则事前明确。
4. 次要opposedmass `0.5*(TV(μz,q0)+TV(p,μz)-D)`是三角缺口，不当成额外独立机制确认。两档测试保持独立报告；R8 F-source的p/qh概率身份按旧采样口径准确重构。
