# 从原始跨领域残差观察重新确定论证重点

> 论证更正：跨领域聚类作为动机保留；多领域有效、乃至留一域迁移，不单独构成相对已有条件修正的贡献。下文“科学主线”按[当前对照决策](NEXT_BASIS_CHECK_CN.md)收缩为误差选方向是否具有额外修复价值，跨域作为适用范围证据。

2026-10-16。用户补充方法起源后修订研究判断。本文记录问题、已核实依据和理论联系；不启动新实验，不改写已完成实验结论，不作为训练 prompt。

## 1. 调整后的核心问题

**在固定目标—草稿组合内，不同领域反复出现的相近失配，是否共享有效的修正规律；这种共享在什么条件下成立，何时失效？**

用户报告的开发过程是：最初考虑微调模型后做模型选择；LoRA 实验效果不好；随后收集目标与草稿的概率残差，观察到不同领域的残差混合成簇，因此转向当前修正方案。这是开发动机。LoRA 的负结果本身不证明领域适配无效、梯度冲突或输出修正必然更优。

据此，把“提高单位计算成本的纠错收益”移到方法价值层。科学主线是失配的跨领域可复用性及其条件。头、固定基底、低秩、聚类专家都是可能的实现，不是预先必须成立的结论。相近失配也不必形成几个边界清楚的离散簇；连续共享方向同样可能是合适描述。

## 2. 本次实际核查的早期证据

早期归档 `docs/experiment_archive_20260923/output_metadata/mismatch_clusters_ori/` 保存了四域各 20000 条、总计 80000 条事件的聚类摘要。领域为 code、math、natural_questions、summarization。

核查全部 `pca_64/pca_256 × k4/k6/k8` 摘要，而非只挑一张漂亮图：

- 仅方向聚类的 domain NMI 约 0.0041–0.0072，说明这些分组与领域标签关联弱。
- 相应 cosine silhouette 约 0.0134–0.1437；PCA64/256 保留方差约 41.5%/61.9%。分组清晰度及稳定性依赖处理方式，不能写成发现了若干稳定自然类别。
- 摘要记录的输入是归一化的 4096 维 `e_res`，不是未经变换的完整词表概率残差。存留的后续采集代码 `residualV2/runtime_basis_hooks/mismatch_runtime_dump.py` 使用稀疏可表示词表上的 W 投影，并保留 `e_res` 兼容别名；它不能单独证明最早 ori 采集的精确实现身份。
- 归档 README 说明清理过原始大张量。本次找到的是摘要，尚未确认能逐样本重放最早聚类。

因此已有事实是“指定残差表示中的聚类不按领域分开”，还不是“同一类失配在另一领域可被同一种动作修好”。簇与领域独立也不等于残差与领域独立；随机分组也可能有很低的 domain NMI。

还核查了后续更直接的负结果：`mismatch_expert_headonly_30k_20261012_v2/RESULTS_CN.txt`，三种子、每域 10000 条头训练，mismatch 双专家与学习 router 相比同活跃参数通用头，T1 overlap 差为 −0.098pp，95% 区间 [−0.140, −0.052]。这不支持已有双专家方案的优势。它没有单独定位失败来自聚类、专家训练还是路由，不能反过来认定共享结构不存在，也不能改写成共享结构已经得到验证。

## 3. 理论应连接“相近”与“可共享修复”

一个可直接证明的充分条件说明所缺的联系。它是三角不等式的应用，不是新定理或创新性证明。

固定若干状态，令完整词表残差 `r_s = p_s - q_s`，原始距离 `d_s = ||r_s||_1/2`。设共享有符号修正向量 `c` 满足分量和为零，选取 `0 <= t <= 1`，且每个 `q_s + t c` 都是合法概率分布。记 `e_s = ||r_s - c||_1/2`，则

```
TV(p_s, q_s + t c)
 = ||(1-t)r_s + t(r_s-c)||_1/2
 <= (1-t)d_s + t e_s,

TV 改善 >= t(d_s-e_s).
```

因此，当组内每个状态的残差离共同修正都比离零更近（`e_s < d_s`），存在上述合法正步长时，共同动作可以改善每个状态。领域标签不进入这个充分条件。

这个结论不是必要条件；条件不满足不能判不可修。其意义是把可以测量的残差离散程度、修正幅度和实际 TV 收益连起来。全词表中极小概率可能使合法步长非常小，因此“存在步长”不等于有实质收益。

映射当前实现时不能省略以下差别：当前头输出经过 W、固定基底、Top256 mask 和 softmax，实际概率变化随状态而变；不能把其 logit 向量直接当上述概率向量 c。归一化投影空间中的余弦接近也不保证完整概率残差的 e_s 小。必须在实际合法动作族内建立或检查相应条件；如果仅在宽松概率空间成立，就只得到修复潜力，不能解释原头收益。

这比重新证明“保留多少 PCA 能量”更贴近原始观察，但上述标准充分条件本身尚不构成论文的理论创新。新增认识应来自真实失配满足什么共享条件、覆盖多少状态、如何跨领域迁移以及何时条件破坏。

## 4. 应优先补的直接证据

需要区分两个解释：

- H1：相近残差对应可跨领域复用的有效修正。
- H0：混合聚类主要反映共同词表/输出几何、常见 token、归一化或降维；对修正迁移没有额外意义。

首要证据是源领域得到的修正规律，在未用于构造或调参的另一领域同类失配上是否仍有效，并与匹配预算和动作尺度的通用/不看残差几何对照比较。只用目标域 p 做事后诊断时，须明确为 oracle 描述；运行时模式选择必须依靠草稿可见输入，不能借用待预测的 target 残差。

“跨领域同类失配”与“同领域不同失配”的比较可帮助检验领域标签是否足以描述纠错关系，但须控制概率集中度、失配幅度、候选/token 构成等混杂；不能用这项相关比较替代直接迁移证据。使用旧数据只能算探索，不能称未见确认。

若几何相近但修正不迁移，跨领域共享修复解释不获支持。若只在投影空间成立、完整词表不成立，应归于表示局限。若共享规律可迁移但当前头未实现，应区分理论可达性和方法学习差距。已有专家负结果保留，不自动重启专家训练。

R9 限制的是某组状态共用同一个最终预测；本问题允许 q_s 不同、修正幅度不同，不能直接移用其数值上限。机制发现的零候选结论仍有效；本修订没有把它追认为任何训练来源的确认。

## 5. 核心问题审核

- 初稿“跨领域聚类说明需要聚类专家”：**不通过**。混合聚类不证明修复共享，已有专家结果也不支持这个方法结论。
- 修订“跨领域相近失配是否共享有效修正规律及其条件”：**问题定位通过**。直接对应什么失配能共同修、为什么、何时失败。
- 直接证据：源领域构造、目标领域固定规则的修正迁移，辅以几何与非残差对照；允许推翻共享解释。
- 旧证据：保留聚类的降维/归一化限制、双专家阴性、R9 适用范围、机制发现零候选；不把低 NMI 或标准数学工具当新发现。
