核心判断
用户提出的机制有结构依据：DFlash 的后续块内采样没有更新一次前向得到的 hidden，而 EAGLE-3 把实际采样 token 输入下一次递推。七步正式结果及 DFlash 的后位置收益符合这个解释，但尚未识别它占收益多少，也未排除训练、表示、支持集与误差分布的影响。
新颖性必须收紧：DSpark、Domino、DFlash-2、TreeFlash 已补因果依赖；DeLS-Spec 和其中的 Domino-FT 还覆盖冻结已有 DFlash 后加头。不能把 lag-1、低秩、logits 残差或冻结 backbone 本身作为首次。
较可辩护的研究定位是：对冻结 target–draft 对，利用训练期 mismatch 选择固定修复子空间，按当前 hidden、原 proposal 统计与实际前驱预测残差方向及幅度，并系统区分好解是否存在、共享小头是否学得会、研究留出是否泛化、native 是否有净收益。这是候选贡献，仍需直接近邻及基底必要性证据，不能仅换名称确认创新。

二、lag-1 的精确含义
C 表示已验证上下文，包含真实 anchor。DFlash 一次算出各位置不同的 h_j 和 q^0_j(.|C)；原生独立取样时，后位置看不到本块前面实际取到的 token。它有历史条件信息，但缺少这种后来才实现的块内条件。第一个 proposal 的前驱本来就是已知 anchor，不享有新增块内信息。
EAGLE-3 每步用当前真实 input token 与递推 hidden 执行下一次 draft forward。因此我们的硬前驱分支主要提供另一条直接利用已有条件的路径，而不是在原生从未观测的 token 上增加新信息；仍可能改善有限容量预测、表示提取或校准。递推本身有近似误差，不能把 lag-1 具备等同于条件分布已正确。
源码中 q 必须区分：raw logits u；特征概率 q=softmax(u)；修复后 logits z；经过实际采样处理后的 proposal r。verifier 的 qbuffer 名称虽然是 q，内容可以是 processed logits，不能据变量名认定 softmax 已经执行。
完整 q 与 logits 并不互相冲突：温度固定、概率为正的精确算术下，log(q_v/q_w)=(u_v−u_w)/T，softmax只去掉共同偏移，保留相对logits。TopK选择、moment聚合、低精度和数值下溢是另外的表示问题；聚合不等于必然丢掉全部候选信息。q由完整hidden和冻结LM head确定，显式q并不增加独立信息，作用是网络更容易利用已有proposal结构。我们的输入读取概率，但最终仍在logits空间做残差并用实际修正proposal采样；不能按论文图里写logits就判定方法不一致。

四、可用的数学解释及边界
以下是理想分布族恒等式，不是本项目已测得的信息量；numerical witness 已在 mathematical_audit_v1/math_checks.json 验证，本次未重复运行该测试。
P(X_1:m|C)=∏_j p_j(X_j|C,X_<j)，原生并行 Q0=∏_j q^0_j(X_j|C)。
KL(P||Q0)=TC_P(X_1:m|C)+Σ_j KL(P(X_j|C)||q^0_j(.|C))。
第一项是独立采样缺少依赖的误差，第二项是边际近似误差。因此，即使各位置边际完全正确，也未必能组成正确的联合路径。
若允许任意表达能力的一阶 Markov 头并完整保留 C，最小剩余 KL=Σ_(j≥2) I(X_j;X_<j-1|C,X_j-1)。与理想独立族相比能去掉的部分为Σ_(j≥2) I(X_j;X_j-1|C)。实际固定特征、受限候选/基底、小网络远未保证达到这个投影。
EAGLE 的原生递推族已依赖 X_<j，所以没有同样的强制独立采样限制；仍有容量、近似、表示和训练分布误差。该分布族论证只能支持方向，不能推导实际 AL/TPS 增量。
对正概率的完整词表 q0，理想 logits 残差 δ*=log(p_full/q0)+共同常数；可分解为 log(p_marg/q0)+log(p_lag1/p_marg)+log(p_full/p_lag1)。分别对应边际拟合差距、已实现前驱的条件响应、lag-1之外的历史残差。当前 head 只是这类残差的受限近似，不在 inference 读取未知 target 概率。
DFlash 中 u=hWᵀ、p归一化且作为常量时，负 KL hidden 梯度为(p−q)W。基底从这类方向的加权未中心化二阶矩选取，不是 logits PCA；候选修正约为 δ_I(v)=a||h||〈W_v Bᵀ,d〉。随机/其它基底与此机制的同预算比较仍是必要性问题。既有 rank/TopK 扫描已经做过，不能当作未执行新实验。
EAGLE 特别边界：当前代码用(p_full[M]−q_M)W_E，teacher子集不重归一化。若子集质量s<1，严格子集 KL 的负梯度是(p_M−s q_M)W_E，当前残差不等于该式；而 vocab外q=0时完整KL还有支持问题。因此仅在 DFlash 全词表设置使用严格“KL梯度基底”解释，EAGLE称对应子集 mismatch 残差基底；保留当前实现证据，不擅自修代码或重训。
T1 精确单前缀 overlap=Σ min(p,r)=1−TV(p,r)，但真实 E[AL]=1+Σ P(全部前缀被接受)，涉及真实存活路径。OUTPUT 的 teacher-path overlap cumprod 是代理，不能等同于全部随机路径期望；overlap改善也不能保证T0 argmax改善。

五、相对于已有工作的贡献边界
最重要的直接对照是 DeLS-Spec 的局部 Markov/RNN 以及 Domino-FT，而不只比较 RAW。状态 hidden/q 可以区别于独立局部语言模型，但 Domino-FT 已提供 hidden 条件残差，DFlash-2已有hidden门控配对。必须回答固定 mismatch 基底、方向/dose 参数化或学习诊断到底带来哪项可重复收益。
可写的候选贡献：① target–draft 对特定的训练期 mismatch 子空间与受限候选残差；② 冻结并行/递推 draft 的统一原生 proposal 修复合同与适用边界；③ 在同一研究链中分离可达性、状态条件响应、共享优化、泛化和真实延迟，并报告成功与失败。前两项仍需匹配近邻、独立研究留出与数据/表示控制；第三项不能把41状态推广为普遍定理。
不可写：首次给 DFlash 加 lag-1；首次 logits 修正或低秩；首次冻结 draft 外接头；q 是额外信息；EAGLE 小收益已证明 sole cause；oracle41/41证明输入充分；T1收益代表全面解决T0；任何跨论文SOTA/保证会议等级。

六、既有实验如何支撑，如何限制
前驱响应干预固定h/q/候选/basis并重算改变前缀的teacher：96上下文，方向cos约0.523；预测与teacher条件响应q加权cos约0.440，可置信替代前驱子集约0.583；原前驱 RAW正确56→repair61，同时修好10、误修5。支持已学到部分条件响应，不证明全部收益由lag-1造成，也不证明足够拟合。
线性候选包络与最终头oracle：所测41错误都有好解；固定当前方向只调dose仅11/41。支持方向选择重要；放宽oracle与学习头的可达集、LN/方向参数化及输入映射不同，不能推导可学习/泛化。
冻结DFlash前驱/前缀揭示实验退化：揭示token违反其all-mask训练分布，不能作为历史无用或依赖贡献为零的证明。
OUTPUT后位置权重衰减和共享梯度干扰已诊断，无普遍latent坍缩；显式交互头、TV/NLA、简单epoch早停均未超过旧N；oracle标签开发收益小，28状态可拟合，16/64prompt训练好但研究留出无改善。留出曾用于历史开发，不能当独立最终测试。
已有A–G输入/层数/尺度消融没有把当前no-soft2的硬前驱完整因果收益单独识别出来；旧A–G主要移除hidden或soft反馈等，不应误称已完成同预算no-hard因果证明。
最新target-hidden/logits/合并三组都已完成：没有形成稳定超过旧N的结果。TargetHidden在C1 T1对旧N TPS+1.11%，C40 T1却−0.92%；其余两组T1对旧N也没有净增益。这不支持“只要换成logits/加target hidden就解决问题”。
OUTPUT+Top16 CE也已完成，但遵照授权只测新head，没有同轮RAW/N，不能给配对提升百分比；候选CE基于正确答案标签，不是author未公布的rank loss。

七、未证明项怎样补证（研究建议，不是本次执行队列）
先利用现有正式计数和固定状态前驱干预做位置/候选兼容分析；本次已完成位置CSV，尚未得到真实数据上的conditional mutual information。
若后续授权因果实验，优先针对“lag-1贡献份额”做同数据/同预算的硬前驱控制，区分重训去分支与对已训练网络的OOD输入替换。DFlash块首是天然对照，但首/后位置差异仍受难度和分布影响；不要把新一轮完整A–G或revealed-prefix OOD重复当新证据。
若后续授权创新性实验，优先直接近邻在同一冻结checkpoint、数据预算、support、proposal长度及formal protocol下的复现，以及固定basis必要性控制。以前TopK/output-rank/basis重拟合混合变化的组不是纯随机/梯度子空间对照。
若需要强化普适性，先匹配 EAGLE/DFlash 的训练面板与接口核验，再作跨多个 target–draft 对及独立新面板的确认；当前并无这个因果/泛化结论。

八、可用于论文引言的谨慎表述
并行草稿的误差同时包含边际近似不准和已实现块内前驱未参与条件化；递推草稿已具有后者的输入机制。本文研究冻结 target–draft 对的受限残差修复：从训练期 mismatch 选择修复子空间，利用原 proposal、draft hidden 与实际采样前驱生成方向和幅度，并在原生验证器中使用实际修复 proposal。我们通过条件干预、oracle 和共享学习诊断区分修正可达性与可学习性，同时报告该方法在并行与递推草稿上的收益及延迟边界。
这段是定位草稿，不包含“首次”“普遍提升”或“已优于近邻”；正式稿必须增加 DeLS-Spec/Domino-FT 等的匹配比较。

九、原始来源与定位（机制比较；不搬运性能百分比）
[EAGLE3] EAGLE-3: Scaling up Inference Acceleration of Large Language Models via Training-Time Test
原文：https://arxiv.org/html/2503.01840v3
定位：§2.2; §3.1, especially the sampled-token embedding and subsequent-step inputs; §3.2
机制：实际采样 token 的 embedding 和上一步 draft 输出进入下一次递推；训练模拟递推输入。
与本项目关系：直接支持 EAGLE 原生已有实际 lag-1 条件输入。
边界：有条件输入不等于条件分布预测准确，也不排除残差修复；不能仅凭输入机制推断剩余提升。

[DFlash] DFlash: Block Diffusion for Flash Speculative Decoding
原文：https://arxiv.org/html/2602.06036v1
定位：§4.1 target-feature-conditioned parallel drafting; §4.2 anchor and mask block
机制：已验证 target 特征和真实 anchor 条件下，一次前向产生整个 mask 块各位置 hidden。
与本项目关系：块内后续真实采样 token 不进入已完成的 backbone 前向，是条件依赖缺口的结构依据。
边界：已有已验证历史、target 特征和 anchor；各位置 hidden 不相同；实际实现是边际近似而非已证明真实边际。

[DSpark] DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation
原文：https://arxiv.org/html/2607.05147v1
定位：§3.1 parallel/sequential stages and Markov/RNN heads; §3.2 scheduler; §3.3 training
机制：并行 base logits 后叠加实际前驱/前缀驱动的 Markov 或 RNN 转移偏置，并训练置信度调度。
与本项目关系：补足块内因果依赖、低秩转移、CE/TV 与接受相关监督均已有先例。
边界：联合训练和调度贡献不能等同于单个 lag-1 头；本文性能数字不用于和本项目跨口径排名。

[Domino] Domino: Decoupling Causal Modeling from Autoregressive Drafting in Speculative Decoding
原文：https://arxiv.org/html/2605.29707v1
定位：§4.1 causal recurrent head and hidden-conditioned correction; §4.2 training
机制：GRU 编码实际块内前缀，再结合位置 hidden 产生低秩 logits 残差；原论文联合训练 draft。
与本项目关系：hidden 加前缀、连续残差、低秩修正和 causal repair 本身不是可独占创新。
边界：原论文联合训练与 DeLS-Spec 中的冻结版 Domino-FT 必须区分。

[DFlash2] DFlash 2: Keep Drafting Parallel
原文：https://inco.ai/blog/dflash2/
定位：The Right Tokens Are Already There / A Lightweight Path Selector; Suffix Decay Is a Local Problem
机制：Top16 候选的相邻 token 配对分数由原 logits、token 因子和 hidden 门控组成；rank256；分数并行预计算后逐步选择。
与本项目关系：hidden 门控 lag-1 交互、候选内修正与低秩配对已存在。
边界：作者文章未公布独立 rank loss；公开作者机制与社区训练 recipe 分开。额外卷积也不等于采样 token 更新 backbone。

[DeLS] DeLS-Spec: Decoupled Long-Short Contexts for Parallel Speculative Drafting
原文：https://arxiv.org/html/2607.07409v1
定位：§4.1 omitted long/short residual interaction; §4.2–4.3 local-head training/fusion; §5.5 Domino-FT; §5.7 cost
机制：固定 DFlash，独立训练局部 Markov/RNN 语言模型，以长/短 logits 和 unigram prior 融合；还评测冻结 DFlash、只训练 Domino 头的 Domino-FT。
与本项目关系：最关键近邻：冻结已有 draft 后加小头，也不能单独主张首次。
边界：我们的状态依赖只能区别于其纯 local expert；Domino-FT 已有 hidden 条件修正。尚未在本项目同配置复现这些基线。

[TreeFlash] TreeFlash: Parallel AR-Approximation for Faster Speculative Decoding
原文：https://arxiv.org/html/2606.03819v1
定位：§3 AR-Approximation and two-stage tree construction; training description
机制：SwiGLU 结合位置 hidden 与前驱 embedding 近似 AR 条件状态，再用于树构建；从 DFlash 初始化并微调。
与本项目关系：轻量 hidden/lag-1 adapter 和条件分布近似有直接先例。
边界：树节点预算与单链 proposal 数不同，不能拿绝对 AL 直接比较；不是冻结原 checkpoint 的本地复现。

[LiLiCorr] LiLiCorr: Lightweight Likelihood Correlation of Parallel Drafts for Speculative Decoding
原文：https://arxiv.org/html/2608.20530v1
定位：§3.2 candidate-node inputs and target-anchor fusion; §3.3 local normalization; Appendix A confidence features
机制：候选 token embedding、slot hidden、置信度特征和 rank/位置编码经过小 Transformer，融合 target anchor hidden，输出相邻候选配对分数。
与本项目关系：原 proposal 置信度、target hidden、全块候选上下文和条件选择均已有相关使用。
边界：联合训练 backbone；候选配对与我们的固定 mismatch 子空间不同，但不能以使用 q 或 target hidden 单独声称创新。

[DPACE] D-PACE: Dynamic Position-Aware Cross-Entropy for Parallel Speculative Drafting
原文：https://arxiv.org/html/2605.18810v1
定位：§3 accepted-length confidence-product surrogate and position weights
机制：由前缀置信度乘积的平滑接受长度代理导出位置权重，用于 CE。
与本项目关系：前缀接受相关目标和动态位置监督已有先例，适合作为 OUTPUT 梯度诊断的相关工作。
边界：置信度乘积、teacher 路径 overlap 乘积与真实 native 存活期望分别定义；不能把代理写成严格相等。

[FlexDraft] FlexDraft: Flexible Speculative Decoding via Attention Tuning and Bonus-Guided Calibration
原文：https://arxiv.org/html/2605.20022v1
定位：§4.2 Bonus-guided Calibration, Eq.4
机制：把已解析的 bonus token embedding 与 mask hidden 输入两层 MLP，加到 draft logits，联合训练校准头与 attention tuning。
与本项目关系：已实现 token 条件化的 mismatch 校准有先例。
边界：解决跨验证周期、提前准备下一块时未知 bonus 的问题；本项目 DFlash 的 anchor 已知，关注同块内后来采样的前驱，二者不能混同。

[KVShot] When Hidden States Drift: Can KV Caches Rescue Long-Range Speculative Decoding?
原文：https://arxiv.org/html/2604.26412v1
定位：§2 context-information view; §4 shallow queries and sparse KV gradients
机制：用 KVShot 诊断 hidden 复用、KV 复用和混合复用，讨论压缩、递推漂移与优化瓶颈。
与本项目关系：提醒 EAGLE 已有 lag-1 时仍存在其他误差来源，AL 较小增益不能归于唯一原因。
边界：论文的诊断解释不是我们模型已验证的根因，也不能把其吞吐或隐状态结果搬成本项目证据。

[PUNT] Parallel Sampling from Masked Diffusion Models via Conditional Independence Testing
原文：https://arxiv.org/html/2510.21961v1
定位：dependency-aware parallel unmasking and confidence/dependence distinction
机制：根据依赖关系组织并行 unmasking，而不只看单 token 置信度。
与本项目关系：概念上支持“边际置信度高不等于联合路径兼容”。
边界：masked diffusion 的 unmasking 任务，不是本项目 AR target 的精确 speculative verifier 和 native 吞吐基线。

[TT] Tensor-Train Joint Modeling for Few-Step Masked Diffusion
原文：https://arxiv.org/html/2607.03788v2
定位：joint distribution parameterization and factorization-bias analysis
机制：用 Tensor-Train 联合参数化处理独立位置预测的分解偏差。
与本项目关系：条件依赖缺口可作为理论动机。
边界：HTML 版本标题与部分索引的 Discrete Diffusion 标题有差异；本文只使用链接版本。非本地 speculative repair 方法复现。

[ExactSD] Fast Inference from Transformers via Speculative Decoding
原文：https://proceedings.mlr.press/v202/leviathan23a.html
定位：modified rejection sampling and exact target distribution
机制：正确记录实际 proposal 分布并做标准拒绝采样，可保持 target 分布。
与本项目关系：修复后采样与 verifier 实际 q 一致是方法合同。
边界：精确投机采样保证属于基础算法；完整本地运行的数值等价性必须另验证，不能当作新创新。
