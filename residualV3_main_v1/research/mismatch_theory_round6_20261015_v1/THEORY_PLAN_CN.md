# 第六轮研究设计：历史、失配与修复成败

执行细则见 [EXECUTION_GUIDE_CN.md](EXECUTION_GUIDE_CN.md)，交接入口见 [START_PROMPT_CN.md](START_PROMPT_CN.md)。

## 1. 这次要回答什么

**草稿面对不同历史时，哪些偏差仍然同向，哪些会改变方向；这种改变是否能从已有历史中预测出来？**

原头只是固定的观察对象。我们不从三路输入推销新结构，也不预设历史足以解释所有失败。预测器用于检验历史中有没有可提取的风险信息，不输出新的草稿分布、不接入解码。

本轮依次回答：

1. 第五轮的共同纠正方向，到了真正未见的历史还有效吗？
2. 不看当前位置target，历史能否预测原头何时受损？
3. 这种预测来自历史与当前状态的正确对应，还是仅来自更多参数或粗略统计？
4. 能否进一步预测收益幅度，以及一个预先选定token应提高还是降低概率？
5. 原头一好一坏时，还有没有能兼顾两支的修正空间？

## 2. 已有证据给出的起点

|已有发现|本轮不能跳过的缺口|

## 3. 失配先于方法

固定 `C=(已验证上下文、anchor、位置i)`。`H` 是当前token之前的完整块内历史；`p_H` 是target条件分布；`q0` 是并行主体的原始分布。`Z` 是原头实际读取的完整输入，`qh=F(Z)` 为冻结原头输出。

固定C与Z时：

```text
p_H − q0 = (E[p_H | C,Z] − q0) + (p_H − E[p_H | C,Z])
             该条件下的平均偏差             历史带来的分支差异
```

平均偏差不意味着每条分支每个token都同向；均值为零的历史差异也可能使同一动作一好一坏。这个标准分布分解不是新定理，不识别容量或训练原因，也不能当作TV收益的可加分解。

R5提供了有限证据：存在可迁移的共同偏差，也存在需求反向的真实历史。R6检验它们的**稳定范围与可预测程度**。若预测成立，补上“历史变化能在看见target之前被利用”的证据；仍不等于得到最佳修复动作或在线收益。

## 4. T1：共同方向能否跨到未见历史

新题固定48条，GSM8K/HumanEval/Alpaca各16条。每个有效anchor自然采样64个分支，前16个fit、后48个eval。`C/i`相同、完整H未出现在**全部fit历史**中的eval状态才叫novel；不只在匹配Z组内查重。

沿用R5共同偏差探针：同C/Z的fit中，令 `u(v)=max(0,min_H[p_H(v)−q0(v)])`，`o(v)=max(0,min_H[q0(v)−p_H(v)])`，`U=sum u`、`O=sum o`、`M=min(U,O)`。M>0时：

```text
r = q0 + (M/2)·u/U − (M/2)·o/O
```

M=0时r=q0。fit上TV改善是构造保证。待检验的是：冻结r后，novel eval上的 `TV(p,q0)−TV(p,r)` 是否仍为正，损伤多少。

主量 **HN** 只覆盖fit至少2个不同H、eval匹配完整Z且H真正未见的集合。另报seen、novel和未匹配分母及效果；seen与novel均值差不是随机干预效果。重复自然采样保留原频数，去重H等权仅作描述。不补采到出现novel或冲突。

这是同C条件迁移，探针使用fit target且允许全词表动作；不是跨题预测器，也不是原头可达动作。M=0或novel失败都不能证明不可修。

## 5. T2：历史能否预测冻结原头的损伤

对每个状态定义：

```text
Δ = TV(p_H,q0) − TV(p_H,qh)
y_bad = 1[Δ < −1e−5]
```

预测目标始终是**原头实际修正结果**，不是T1探针收益。旧R4的48条新题用于训练，旧R5的36条新题用于开发；新R6全部合格eval主状态用于测试。所有分支随题面整体分配，不能把同一题的不同历史拆进train/test。新题fit标签仅供T1，不能进入预测器训练、标准化、校准或阈值选择。

|设置|能看到什么|检验用途|
|---|---|---|
|A|完整raw hidden、紧邻前驱静态embedding、实际q路投影qp、fusion_concat及固定共同标量|已有可见信息基线|
|B|A加有序的更早块内历史，去掉已在A中的紧邻前驱|历史额外预测价值|
|B置乱|同一冻结B，在同C/i/精确Z内打乱更早历史对应|参数和模型不变，检查正确历史对应的价值|

qp与fusion是已有信息的确定性变换，不是独立新信息。预测器输入不含当前位置target分布、target运行得到的历史hidden/likelihood、TV、oracle、当前/未来token或fit覆盖标记。仅静态embedding lookup允许。完整特征、单隐藏层width32 MLP及训练上限见执行指南；不搜索结构或增加模块。

主量 **HP = Brier(A)−Brier(B)**；**HC = 平均8次Brier(B置乱)−Brier(B真实)**。HC与HP采用同一测试人群；先算每次损失再平均，不能先平均概率产生额外集成收益。只有一个历史的组仍计入，差为零；缺数据不填零。

同时给训练先验常数基线、损伤prevalence、PR-AUC、旧dev锁定阈值的test recall/FPR和校准。Brier变好但检出没有改善时，只称概率预测改善。A/B均不如常数基线时，不包装成可用风险识别。B参数更多，因此HP与HC应一起解释；单个正结果不能代替另一个。

## 6. T3：收益大小与需求方向，作为次要检验

沿用相同train/dev/test与A/B历史表示，有限拟合：

- 用固定ridge预测连续Δ，报MSE/MAE及训练均值基线。
- 仅依据q0/qh选 `v*=argmax_v|qh(v)−q0(v)|`，相同值取最小token ID。预测 `p_H(v*)−q0(v*)` 的上/下/中性，数值带1e−5。A/B共同读取v*静态embedding与q0(v*)、qh(v*)，然后用固定线性三分类器。

标签所需target只在离线监督/评估使用；v*不得根据p挑选，也不能换成实际当前位置采样token。该任务在原头输出可计算后预测，不声称在运行头之前已得到决策。

单token方向预测正确仍可能整体受损，朝对方向也可能过量；这两种标签必须分开。T3没有输出可执行的完整修复分布，不承担主检验失败后的“替代成功”。

## 7. T4：方向翻转后是否仍有共同空间

用同C/i/Z、不同H的真实分支，呈现p、q0、qh及逐token TV贡献。优先同长且更早历史仅1个token不同的案例；自然历史对比不是语义因果实验，多处差异不能归因于某一个词。

全轮最多12对（每域2异号、2非异号，固定排序选择），复用R4的S/U松弛 `R_ind/R_shared/R_safe` 诊断。S=raw Top256，S内概率可松弛调整；U内条件比例保持raw，仅U总质量可变，与T1全词表自由调整不同。安全指相对raw两支均不受损。保留完整尾部，不能合桶改变问题。仅调用既有固定求解器、100轮上限；数值未证保留界与失败状态。

若返回候选确实让两支都严格改善，说明**这个松弛操作集合**里还有共同空间；不证明原头basis/剂量实际可达。最优均值改善但只有一支改善，或求解未收敛，不能说没有两支都改善的动作。按标签挑选的12对是解释性案例，不能估计整个人群失败成因比例。

## 8. 哪些结果会改变我们的判断

|结果|允许的结论|仍不能声称|
|---|---|---|
|HN支持|共同偏差可迁移到预定同C/Z未见历史子集|跨题最优修复、所有历史可修|
|HP与HC都支持且覆盖足够|固定预测家族能从正确历史对应中提取原头风险信息|历史充分、在线gate有效、原因一定是缺历史|
|HP支持但HC不支持|新题整体概率预测有增量，同Z对应证据不足|已定位分支层历史对应机制|
|HC支持但HP不支持|这个B内存在对应价值，但没有超越A的整体证据|新增历史普遍改善预测|
|主量不确定/覆盖不足|这次有限测试尚不能确认|历史无信息或两者等效|
|方向可预测而风险不可预测|局部需求可提取，整体损伤仍难预测|正确方向必然修好|
|松弛空间仍有共同改善|这些选定案例损伤在松弛集合内并非必然|原头可实现、训练已找到|

HN/HP/HC分别给双侧98⅓%区间及预定覆盖，详见统计合同。各自可成立或不成立；不把多个有限发现合成“一般失配理论已证明”。

最终讨论回到三个问题：**什么偏差仍可共同修、历史为何使需求改变、这种变化能否提前预判。** 原头结构和预测器实现用于检验这些问题，不成为论文顶层叙事。
