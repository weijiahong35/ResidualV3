# 证据与目标

|主张|证据|状态|限制|
|---|---|---|---|
|共同偏差能迁移到独立抽样分支|R5 H_shared|已支持|大多H已见，不是全部新H|
|纯新H也有稳定共同方向|R6 T1|待检验|同C/Z条件子集，fit target只供诊断，不供预测器|
|历史能预测原头损伤|R6 T2新题Brier与同Z打乱|待检验|限定特征/预测器，不能推在线收益或充分信息|
|历史能预测需要提高还是降低|R6 T3固定token方向|次要探索|单token，不是完整修复方向或新分布|
|反向需求必然无共同动作|R4反例|不应声称|R6仅最多12组松弛诊断，不等于真实basis可达|
|某语义类别必导致方向翻转|尚无盲标确认|待验证|自然历史对照只给具体分布对比，不宣称单词物理因果|
|预测失败证明历史无用|无依据|不应声称|可能是表示、样本、探针能力限制|
|预测成功证明容量原因|无依据|不应声称|仅支持可提取关联/跨题预测价值|
