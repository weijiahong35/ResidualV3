# 第六轮：历史怎样改变失配，以及能否预判修复成败

版本：2026-10-15。当前目录是执行方案，尚无第六轮实验结果。

第五轮说明：部分预测偏差可以共同纠正，但更早历史也会改变target需要的方向。现在要补上两个环节：**共同方向能否迁移到真正未见的历史；只看推理时已有的信息，能否预判原头会修好还是修坏。**

- [研究设计](THEORY_PLAN_CN.md)：问题、检验、反证与结论边界。
- [执行指南](EXECUTION_GUIDE_CN.md)：资料、数据隔离、固定预测器、阶段与资源规则。
- [启动prompt](START_PROMPT_CN.md)：复制分隔线以下全文给执行chat。
- [资料索引](sources/READING_GUIDE_CN.md)：已有结果、源码与应核对的原文问题。
- [准备核验](qa/INPUT_AUDIT.json)、[合同自检](qa/CONTRACT_CHECK.json)：仅输入和人工小例子核验，不是模型结果。

执行chat收到启动prompt后，可在限定范围内自主采集与拟合小型离线预测器。主体、原修复头、basis、target和安装环境保持冻结。默认共享GPU，显存与余量足够就用，不要求空卡。

本轮总上限：8 GPU小时、24 CPU小时、新增磁盘700 GiB，同时最多1卡。未启用native、随机源排查、TPS评测、训练新头或自动下一轮。
