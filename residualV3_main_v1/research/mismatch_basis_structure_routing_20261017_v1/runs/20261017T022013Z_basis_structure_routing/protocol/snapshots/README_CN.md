# 基底内部结构与上下文选择

这轮只研究基底。先查不同错误实际用了哪些方向，再删去这些方向，看修复是否受损；随后比较在原空间内换组合与另建局部空间；最后检验上下文能否选对空间，以及各组是否适合不同任务。

完整512维基底始终保留作对照。聚类只用训练题；每组128方向，共4组，与总共512方向的预算对齐。胜过单个128维空间不能说成胜过完整512维基底。路由器只选择组，组内修正仍由目标分布计算，因此本轮能回答“选择信息有没有用”，不冒充已经实现可部署修复。

此前真实配对来源优势未建立的结论保留。本轮不再做配对来源对照，也不通过增加训练轮数挽救旧头。四问均允许得到“不支持”或“当前数据无法判断”。

**本轮已完成制文、输入审计和设计审核，未执行科学实验。** 运行性能尚须由新执行chat实测门禁判断。

成功交付应有四个直接答案：共用了哪些方向；当前空间是否受限；可见上下文是否提供选择信息；聚类组是否表现出可重复的任务偏好。不能只交一张平均收益表。
