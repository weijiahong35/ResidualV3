# 动作、方向与选择的数学合同

## 1. 对象和不变性

W∈R^(V×4096)，B∈R^(r×4096)，BBᵀ=I。S为raw q的Top256，A=W_S Bᵀ，a∈R^r，||a||≤R=.8 max(||h||,1e−6)。只对S内logit加δ=Aa；S外保持原logit。

v=Bᵀa称修正向量，||v||=||a||，只是输出修正的参数化，不是对LLM隐藏态实际干预。v的方向与长度分别报告；零向量没有方向。

若B'=OB，O正交，令a'=Oa则Aa不变、幅度不变。因此更换基底坐标不是更换空间。单轴符号、简并特征空间内的特征向量不唯一；不能把“第7根基向量”当唯一可识别机制。各fold的簇号和方向编号都只在该fold内有意义。

所有IN_k均在E512内，删除后的空间也是其子空间；同半径下它们的最优KL收益不能高于完整E512。若数值界严重违反该嵌套关系，先报技术错误，不作科学发现。

## 2. 精确目标及收益界

q_T=Σ_{v∉S}q_v，由完整词表直接求和或稳定logsumexp获得，不从1−候选和相减。p_T同理。对任意a：

```
logZ(a) = logsumexp(log q_T, log q_S + Aa)
f_B(a) = logZ(a) − p_Sᵀ A a
       = KL(p || q'_B) − KL(p || q)
q'_S   = exp(log q_S + Aa − logZ)
q'_T(v)= q_v exp(−logZ), v outside S
grad f = Aᵀ(q'_S − p_S)
Hess f = Aᵀ[diag(q'_S)−q'_S q'_Sᵀ]A >= 0.
```

这在系数欧氏球内是凸问题，不能先把p/q重归一到Top256。最优收益G_B*=−min f_B。a=0可行，故G_B*≥0只是定义。

任意可行a给出Frank–Wolfe间隙：

```
gap = gradᵀa + R ||grad||₂
f(a) − gap <= min f <= min(f(a), 0)
Glo = max(0, −f(a))
Ghi = min(Gmax, max(0, −f(a)+gap))
Gmax = sum_S p_v log(p_v/q_v) + p_T log(p_T/q_T).
```

Gmax是允许任意候选logit变动时的最大KL改善；只用于缺失/未收敛状态的界，不作本方法贡献。上述界在精确算术中成立；FP64实现另加`eps_num=1e−10*(1+abs(f)+abs(gap)+Gmax)`向外扩展，记录未截断gap及所有量。它不是定向舍入的严格认证。若负gap小于−eps_num、可行性/重建误差失控，标numerical_invalid，不修数值救科学结果。

对空间收益差G_A−G_B，用[Glo_A−Ghi_B, Ghi_A−Glo_B]。库最好收益的区间是[max_k Glo_k, max_k Ghi_k]。删除损失、信息缺口、路由收益差均用同样的上下界传播。未收敛项也保留[0,Gmax]等可用界并按原权重进入总体，不能删掉后再宣布通过。

## 3. 固定求解器与方向代表

每个C/i/空间的A先作FP64 thin SVD。只以其数值非零行空间参数化系数，避免A的零空间产生任意方向。在给定实际δ下，该代表是最小范数解；未到精确最优时，不称全局唯一理想修复。

SVD仅可剔除σ≤1e−12σ_max方向，剔除的可能收益影响以`2R*||A_removed||₂`加入Ghi；必须把原A与原空间也列入数值误差记录。此项不小于1e−6则当前解不可作为精确容量标签准入。零映射单独返回G=0，方向NA。不得把截断当成原空间没有该方向。

求解采用投影加速梯度法：初始a=y=0、t=1、L=max(||A||₂²,1e−12)；梯度在y求，a_new=Proj_ball(y−grad/L)；t_new=(1+sqrt(1+4t²))/2，y_new=a_new+(t−1)/t_new*(a_new−a)。每步在可行a_new测f/gap，保留包含零动作在内的最低f可行解。每50步重启加速（y=a_best,t=1）；不按科学收益重启。L是安全Lipschitz上界，不在测试集调学习率。

主求解最多2000步；最好可行解的扩展间隙≤1e−6停止。记录实际迭代、目标、半径、间隙；达上限仍宽则未定，不称“空间不能修”。负收益舍入只用于选择零动作回退，不裁剪原审计数值。

Q1的GLOBAL512动作另从主解继续到1e−8，累计最多4000步；方向准入同时要求主解扩展间隙≤1e−6、精化解扩展间隙≤1e−8，再比较两级解的单位方向余弦≥.999及范数相对变化≤.01（分母max(||v||,1e−12 R)）。达到累计4000步仍未达到精化间隙，或不稳定，则direction_unresolved、方向/系数解释NA，最佳值界仍可用于Q2。||v||≤1e−8R按近零动作处理。该稳定性只是数值敏感性检查，不是病态问题的唯一性证明。

投影必须在B正交系数下进行，不能对候选logit直接套同一个R。不得用伪逆坐标却把它当原系数欧氏预算。

## 4. 删除与共享

轴v_k单位化且属于E512时，删除空间是span(E512)∩v_k^⊥。组IN_k正交时，删除空间是span(E512)∩span(IN_k)^⊥。通过E512坐标内的正交补构造，预期秩511/384，数值检查后使用；不直接把非正交重叠组的矩阵做简单相减。

完整空间与删除空间都重解同一状态。损失只证明在同候选/.8预算/KL下的功能依赖；同轴正负用法不等于相同修复。若删轴无损，可能存在等价替代方向。组的投影/删除贡献有重叠，不能加成总体误差。

坐标平方占比对特定E坐标有意义但不具旋转不变性。组依赖与子空间夹角使用投影算子/主角度，可以比较空间；不从它们单独推出功能。输出表同时保留带符号的候选logit作用，便于知道某方向把哪些候选上调/下调。

## 5. 可见输入与路由上界

先在每fold、每套4组库内建立输入等价类并计算，再按完整面板原权重汇总；不能跨fold把不同动作库合并。对一套4组库，逐状态答案上界V_H=Σ_s w_s max_k G_sk。给定实际输入X，令e为特征完全相同的等价类：

```
V_X = sum_e max_k sum_{s in e} w_s G_sk
V_H − V_X >= 0.
```

这个缺口来自“同样输入必须作同一选择”，与路由训练好坏无关。它只对当前特征和该4组库成立。每类只有一条记录时差为0是定义所致，不代表已经证明输入足以泛化。比较C/i和C/i/previous的类时说明更粗身份类与实际字节类的区别。

路由在折外输入上给出k(X)，其评价为被选组的容量收益；系数仍来自看p后的优化。故最多证明“可见输入含有选组信息”，不能证明同时能预测正确修复方向和剂量，也不证明部署收益。

## 6. 数值核验（工程正确性，不作科学证据）

小词表固定检查：完整KL与动作项/梯度相等；A正交旋转前后动作和最优值相同；删除/IN嵌套关系；FW界覆盖可枚举低维解；零/近秩亏/预算边界；输入类上界包含任意固定路由；自然重复H权重与去重再展开一致。

完整TV必须逐词求`0.5*(Σ_S|p−q'_S|+Σ_T|p−q exp(−logZ)|)`，尾部不能合成一个词。tie固定最小token ID。BF16必须uint16位模式左移16位重解释FP32再FP64，禁止直接数值astype。数学身份正确、求解值可信与真实部署有效分开。
