# 数学与数值合同

本文是标准概率/线性代数工具及固定数值约定，不声明新定理。符号p/q为同一(C,H,i)目标/草稿概率，W为静态输出权重，B为512×4096行正交基底。

## 1. 动作与唯一参考

S为raw J Top256，概率并列按最小token ID；T为剩余词。只在S加logit位移δ=Aa，A=W_S Bᵀ，T的logits固定；完整词表归一化。幅度cost=||a||₂/max(||h||₂,1e−6)，闭包参照上限.8。

```
pT = sum_T p; qT = sum_T q
p_tilde[S] = p[S]; p_tilde[T] = pT*q[T]/qT
r = .5*q + .5*p_tilde
rT = .5*qT + .5*pT
d = log(r[S]) − log(q[S]) − log(rT) + log(qT)
A a = d; a*=A^+d
```

尾部固定使d唯一；d在A列空间内时，伪逆解是实现此分布的最小范数解。原B正交时||a||=||Bᵀa||，只是修正坐标里的位移，不表示真的前向修改了LLM隐藏状态。

A为256×512，满行秩时无预算可实现任意候选位移；此时不同成本不能解释为某基底缺了某个输出方向。没有满行秩也不因浮点截断就宣布数学不可达。

r的安全性由定义保证，不能支持误差信息特殊性。r不必是动作族的TV最优点；本包不解“任意等TV收益”的优化问题，不直接解释接受长度或TPS。

## 2. F与N对应什么

零动作处候选logit的log归一化Hessian为diag(qS)−qS qSᵀ，映射到修正坐标得到W_Sᵀ(diag(qS)−qS qSᵀ)W_S。qS总质量通常小于1；候选内重新softmax会改变动作及曲率。F的逐状态trace归一与谱截断是一个对照选择，不是最优性证明。

N的区间长度给出边际：Σ_k K_jk=u_j、Σ_j K_jk=u_k。验证发生在误差单位化之前；近零误差贡献零矩阵仍保留边的质量。不保证pW_k与qW_j仍有相同上下文、相同候选关系或相同误差长度。

## 3. 分解、重建和未定

- W保存为uint16 BF16位模式，正确解码为uint32左移16再view FP32，之后FP64；禁止直接astype(float)解释位模式。稳定全词表softmax，归一误差≤1e−12，非有限值单列。
- pT/qT直接从完整尾部求和；若为0或必要log值非有限，reference_cost_NA，不加epsilon改变概率。真下溢与非法输入分别记录，可用log域定位，不静默更换参考。
- SVD对A本身使用scipy.linalg.svd(full_matrices=False, lapack_driver='gesdd')；不以AAᵀ正规方程替代。相对秩阈值1e−10；rank<256记numerical_unresolved。
- 解要求||Aa−d||≤1e−8 max(1,||d||)，完整分布重建TV≤1e−8。基底正交误差≤1e−8。
- sigma_low=σ_min−1e−12||A||₂；≤0记未定。
- eta=[||Aa−d||+1e−12(||A||₂||a||+||d||)]/sigma_low。保护区间为[max(0,||a||−eta),||a||+eta]/max(||h||,1e−6)。它不是定向舍入严格证书。
- 相对保护宽度2eta/max(||a||,1e−12)>1e−4记未定；主log比较要求双方保护下界>0。log比保护为log(c_control_low/c_E_high)至log(c_control_high/c_E_low)。
- 上界<.8−1e−6才为budget_feasible；下界>.8+1e−6为budget_exceeded_for_reference；其余budget_unresolved。数值未定不得再标确定可行/超限。
- exact/near-zero、参考NA、数值NA、构造NA各分开；不能写成本∞后当作E胜出。

## 4. 整体增益匹配的单位

每折用训练P全层级权重：g_B²=Σw||A_B||F²/(256×512)，s_B=g_E/g_B。使用s_B A_B得到c'_B=c_B/s_B。g非正/非有限记未定。每个基底每折只有一个s，禁按题/状态缩放。

匹配后的系数范数不等于原B对应的实际位移；其成本比只是排查一个整体输出增益。不能拿匹配后cost<.8声称实际幅度预算内可达，也不能据此排除学习中的初始函数/优化解释。

## 5. 执行前必须通过的小词表核验

1. 完整softmax与候选+tail重建一致；p对修正分布的TV不能合桶。含尾部总质量相等但内部形状不同的反例。
2. r(.5)合法、d唯一、伪逆最小范数及零空间扰动不降低范数；正交旋转B不改成本。
3. F公式与直接小词表Hessian/二阶差分一致；未归一qS时与完整动作一致。
4. 非均匀权重的圆周耦合行列和正确，近零权重保留；符号翻转不变矩阵的反例。
5. N共同有效交集、自然槽权重及等H敏感性在手算小例上正确；三折槽数不同不能平均折均值。
6. 近秩亏、保护宽度、零成本和.8边界必须进入对应未定，不自动记不可修。
7. sA成本与原成本/s一致；匹配尺度不改变原预算标签。

这些只是代码正确性核验。未通过则最多两次定位修复，不能把失败写成科学反证。
