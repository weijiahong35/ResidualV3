# 实验方法：正确错误对应有没有额外价值

## 1. 白话问题与证据链

我们已有“小模型这样预测、目标模型那样预测”的配对记录。真实误差基底比只看全词表输出权重的旧对照更省幅度。下一步要分清：这种优势是否需要正确的配对，还是只要熟悉这批数据、知道两边各自的预测习惯就够了。

固定同一个错误和同一项修正，改变用于提取基底的信息，再看成本怎样变化。这回答修复原因中的一个小问题，不回答原头为什么成功或失败。

|竞争解释|固定观测如何区分|不能额外推出什么|
|---|---|---|
|H_relation：正确配对提供额外方向信息|E在折外规定成本上同时胜F和N汇总|不等于唯一语义机制或失配形成原因|
|H_geometry：候选概率几何已能解释现有量级|E未明确胜F，额外价值未建立|不能由未显著推等价或解释充分|
|H_marginal：两边各自统计可能已经够用|E胜F但未明确胜N，正确配对特殊性未建立|不能由一个错配构造覆盖所有边际解释|

F/N不是穷尽、互斥的因果模型。N也破坏语境和候选对应，并改变误差范数；E/F的单位化约定不同。因此实验阳性仅针对这两个具体竞争构造。

上轮学习TV差为.002892，区间跨0；r(.5)在现有上限内的可行质量E约99.8%、G约99.0%。本包不把学习未实现直接归因于固定基底缺方向。[旧报告](../mismatch_basis_reuse_20261016_v1/runs/20261016T143529Z_basis_reuse/results/RESULTS_CN.md)与[覆盖表](../mismatch_basis_reuse_20261016_v1/runs/20261016T143529Z_basis_reuse/results/COST_COVERAGE.csv)。

## 2. 面板与隔离

只用旧R8的J草稿概率和P来源`pool=='fresh_eval'`记录；位置3/8/15，全部36题/69C/9936自然槽。自然重复H保留，EOS当前合法位置保留，EOS后不补。文件名fresh_test不是新数据。禁止按头成败、novel、reached、P-fit匹配、成本或域收益选样本。

沿用每域完整group SHA排序、零基序号mod3的折；每折24题提取F/N与尺度，12题评价。旧E0/E1/E2分别只对应这些训练题。折外自然槽数为3168/3312/3456，不是假定每折3312。所有同题C及历史必须同折。

每个构造训练集与每个评价集分别使用：C/i内槽等权→题内该位置有效C等权→题内有效位置等权→域内题等权→域等权。明确公式为

`w_j=1/(该C/i槽数 × 题内该位置有效C数 × 题内有效位置数 × 域内有效题数 × 有效域数)`。

所有预期/有效/无效/NA数量均列出。主量汇总完整折外面板时使用36题的原权重，不能把三折均值简单平均。等H只作评价敏感性：C/i内先唯一H等权、同H重复槽等权分摊，再走同一层级；不重建任何基底。

## 3. 三类基底

|标签|训练信息|固定构造|
|---|---|---|
|E|正确配对的p/q，全部词表|直接只读复用旧E0/E1/E2及SHA，不重估|
|F|相同训练C/i的raw Top256、q、W；禁止p|候选KL曲率逐状态trace归一后的加权前512方向|
|N0/N1/N2|训练题同域同位置的p、q加权边际|固定三个稀疏拆配耦合；单位误差二阶矩前512方向|

旧G只引用封存的背景结果，不再次构造、拟合或作为新主判据。总共每折4个新基底，3折为12个；E3个已存在。

### 3.1 E复用

读旧缓存的pW、qW、unit及自然槽身份，核对其零向量规则和旧E训练group。不运行旧construct.py。E取的是unit((p−q)W)非中心二阶矩，不是均值中心化协方差，不按误差长度或TV重新加权。

E/N的零规则一致：`norm(pW−qW)<=1e−12*max(1,norm(pW),norm(qW))`则贡献零外积，保留该槽权重；不能丢零后重新归一权重。单位化是设计定义，不能用谱集中证明一定能修好。

### 3.2 F：只看候选概率的几何对照

令S为J raw Top256，W_S为输出权重行，q_S保留全词表原概率，q尾部质量不删除。对训练C/i计算

```
F_j = W_Sᵀ [diag(q_S) − q_S q_Sᵀ] W_S
M_F = Σ_j w_j F_j / trace(F_j)
```

同C/i的F_j相同，先聚合自然槽原权重，只算一次，不把重复槽当不同数值状态。该F_j是候选外logits固定时、零修正处的KL曲率；trace归一及选前512是本包约定，不是最优基底定理。

trace须有限且大于`1e−12*max(1,Σ_S q_v||W_v||²)`；出现不满足记录时先排数值故障，仍不满足则构造未定，不能静默丢状态或补随机方向。F代码路径不能访问p、pW、pS或reference_gain。

### 3.3 N：保边际、拆对应

每折仅在训练题同域同位置层内拆配；域按名称字典序alpaca/gsm8k/humaneval、位置3/8/15顺序处理。层内槽按(group完整SHA, anchor数字, position数字, slot数字)排序。w_j除层质量得到u_j。

三个种子固定2026101701、2026101702、2026101703。对每个种子新建一个PCG64发生器，按fold0/1/2→域字典序→位置顺序连续取每层permutation(n)，不可每层重置；保存耦合边表与RNG身份。

q端按规范顺序、长度u_j铺[0,1)区间I_j；p端按上述permutation顺序铺长度为对应原u_k的区间J_k，再在圆周统一平移1/2。定义K_jk为两区间交叠长度。稀疏双指针扫描即可，不建n×n稠密矩阵。

核验每行和=u_j、每列和=u_k、总和=1，绝对误差≤1e−12；不靠事后配平修复。非零边的误差为pW_k−qW_j，以层质量乘K_jk为权重。按E同样近零规则单位化并累加非中心二阶矩。

这保留每层p/q原加权边际；不是独立乘积分布，也不是产生置换p值的随机化检验。记录仍为同自然槽、同C/i以及同target身份(group,C,target_row)的配对质量，近零质量、误差长度分布，以及真实/拆配矩阵的相对Frobenius差。相对差分母为max(||M_E||F,1e−12)，≤1e−10则该N在本合同下未改变矩阵，标control_uninformative；不换种子追结果。M_E仅从旧训练unit和原权重重建以核对矩阵，不重估E基底；此3次二阶矩计算也计入性能门禁。整体误差乘±1、只在同C/i重排H都可能完全不改变矩阵，不能代替N。

### 3.4 固定谱处理

FP64对称矩阵，固定scipy.linalg.eigh(driver='evr')取前513特征对，再选前512；每行最大绝对坐标取最小下标并定为正。正交误差≤1e−8；λ512须为正且>1e−12λ1；截断相对间隙(λ512−λ513)/max(|λ512|,1e−300)须≥1e−10。跨截断退化标basis_boundary_unresolved，不换秩/种子/solver追阳性。已选空间内正交旋转不改原范数成本，不把旋转当新修复信息。

## 4. 同一个规定修正、两种成本口径

主参考只用r(.5)，定义与数值状态见[数学合同](THEORY_CONTRACT_CN.md)。候选内向p移动一半，尾部保留q条件形状。实现它所需候选logit位移d对所有臂相同。用A_B=W_S Bᵀ的SVD求最小系数范数，再除max(||h||,1e−6)。只研究这个规定分布，不研究任意同等TV改善的最便宜办法。

逐C回读R8 raw/target，BF16位模式→FP32→FP64全词表softmax；只解码所需P唯一target行并复用。直接尾部求和，不用1−sum(pS)制造极小尾概率。新run可缓存已核验的d、pS、qS、pT/qT、reference_gain和身份；不复制整档。

所有E/F/N的完整分布重建必须核验；相同尾部条件形状下，两份重建分布的尾部L1可精确化为尾部质量差，但p与修正分布之间的TV必须使用全部尾部词，不能把p尾部合桶冒充完整TV。新算E成本只用于全板身份/数值对齐，不能再当新科学证据。

另用每折训练P权重计算`g_B²=Σ_train w_j||A_B,j||F²/(256*512)`，`s_B=g_E/g_B`；比较s_B A_B的成本，即原成本除s_B。所有臂相同训练权重，没有逐状态调尺度。此口径是统一整体增益下的系数成本，不再直接等于原修正向量位移；.8真实幅度可行性只按原尺度判断。

## 5. 固定主量、覆盖与判据

公共场景U固定为参考完整TV改善≥.01，与基底来源无关。保留U外和NA全部分母；条件均值沿完整面板原权重条件化，不筛选后重新等C/题。

- E/F主量：在U中E/F均有可靠正成本的交集V_F上，D_F=加权平均log(c_F/c_E)。
- 三N主量：先取U中E/N0/N1/N2全部有可靠正成本的共同交集V_N；每槽先算三个log(c_N/c_E)的算术均值，再按同一原权重聚合为D_N。不能平均三个不同覆盖子集的总分。
- 各N也在V_N上分别报告；各自最大有效子集只作附表。另报告E/F/N全交集的F/N同场景敏感性，不允许用不同子集均值直接相减。
- 正成本要求cost及保护下界均>0且状态solved；零成本保留zero_cost，不加epsilon做log。原/匹配尺度使用同一有效交集。
- 可靠覆盖为各V质量/U质量；V_F、V_N均须≥90%，各比较至少两域各≥4有定义题。同时列全交集覆盖，不用敏感性挽救主量。
- 原尺度与整体增益匹配口径，D_F和D_N均须≥log(1.10)，数值保护下界仍达到此量级、95%描述区间下界>0、至少两域条件均值正；三个N在V_N上两个口径的总体方向均正。log(1.10)是对照/E比至少1.10，并非E严格少10%。

上述沿用旧研究量级，仅是探索性保留门槛，没有功效计算或新确认含义。域内整题配对bootstrap5000次，PCG64种子2026101704；域顺序同上，每次各域抽12题有放回，相同抽样用于全部比较。按原槽权重乘题抽取次数，在有效交集内重新归一；不重等C或域。域内量只在对应域抽样记录内算。2.5/97.5分位数用linear。没有有效质量的重抽记NA，不重抽补齐；有NA则描述区间不能用于阳性门禁。不能把槽、H或三个N种子当独立题。

bootstrap条件于已建基底，不重估基底，不处理跨折训练依赖，只描述旧样本。有限成本外的总体log比可无界，不能据90%覆盖称全场景优势。数值保护、资源缺失和科学差异不足分开。

## 6. 结果表与停止

|完成后的结果|结论|动作|
|---|---|---|
|E同时通过F、N及尺度/覆盖门槛|正确配对在此单位化构造中提供了超出两类具体对照的规定成本价值|保留窄线，本包结束|
|E对F未过门槛|未建立超出该候选几何对照的增量价值|停止把该特殊性当已支持主张|
|E胜F、对N未过门槛|未建立正确配对相对这些边际对照的增量价值|同上，不声称证明边际充分|
|仅原尺度过、匹配后不过|没有建立超出单一整体增益解释的成本优势|不改尺度/指标|
|覆盖不足、区间宽、域冲突、控制未改变矩阵|未定或对照无信息，不能当不存在|完整报告并结束|
|必要构造/评价未完成|partial，具体input/resource/technical原因|保留已测，不把未测写阴性|

不提供等价性结论。全部工作完成但阴性或统计未定可complete；缺少必需基底、面板或审核为partial。不得自动开启路由、局部基底、更多种子、更多参考点或训练。
