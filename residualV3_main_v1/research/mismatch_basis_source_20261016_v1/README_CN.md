# 基底为什么更省：信息来源对照

**本包只问：从真实错误里提取的基底，是否因为保留了正确的大小模型对应关系，才更省修正幅度？**

上轮已发现：完成同一项规定修正时，误差基底所需幅度的汇总比例约为原几何对照的52%；统一整体增益后，系数成本比例约69%。但小头没有稳定发挥出这项优势。原对照没有看过实际数据，尚不能排除“熟悉常见候选就够了”。[旧结果](../mismatch_basis_reuse_20261016_v1/runs/20261016T143529Z_basis_reuse/results/RESULTS_CN.md)

这次固定修正目标、题目和方向数量，比较三种来源：真实误差；只看草稿候选及概率；保留两边预测、打乱对应关系。只计算完成同一修正需要多大改动。三种来源都不是新训练的小头。

真实误差基底同时胜过两类新对照，才能保留“正确对应提供额外修正信息”的有限解释。未胜出就报告未建立额外价值；不改阈值、不转训路由器。阴性或未定不推翻原方法全部实测收益。

**当前状态：文档与资产头/元数据审核；新实验未执行，完整性能门禁待测。** 本包不解释失配的全部形成原因，不检验基底路由，不声称已经带来学习、接受率或吞吐收益。

用户先读[实验方法](EXPERIMENT_METHOD_CN.md)；交给执行 chat 时复制[启动 prompt](START_PROMPT_CN.md)分隔线以下内容。公式见[数学合同](THEORY_CONTRACT_CN.md)，操作见[执行指南](EXECUTION_GUIDE_CN.md)，固定参数见[JSON协议](protocol/DESIGN_SPEC.json)。

## 固定范围

36题/69C，P来源的9936自然槽，位置3/8/15，3折。每折旧E固定；新建F及N0/N1/N2，共12个新基底。每组512方向；只做r(.5)规定修正，原幅度上限.8不改。全部题已暴露，折外不是新确认或未见领域。

F在本包表示“候选概率几何基底”，不是R8的F轨迹来源。本包不评价D/F来源、不重复27次拟合、不运行LLM或GPU。
