第一轮支持现有头利用前驱对应信息，却未证明条件失配主导，也未建立 native 迁移。进一步研究的对象是受限修正对分布误差的作用；当前 Top256 残差只是一个可精确分析的实例。不要把“Top256”重新包装成理论创新，也不要把标准散度分解写成本项目首次发现。

## 2. 四个层次必须分开

1. **信息限制：** 修复器看不到完整 target 条件分布，最近前驱也不是完整历史。第一轮的分支分析回答部分信息问题。
2. **允许的修正集合：** 即使知道 p，也不是任意修正都能由当前操作实现。此轮分析这一层的放宽集合。
3. **实际学习结果：** 当前共享参数、低秩输出、剂量和训练共同决定实际 q_head。它不等于集合里的最优解。
4. **接受价值：** 同状态 TV 改善要在真实 proposal/reached 测度下才关联连续接受；不能从离线距离直接跳到吞吐。

这四层是研究组织方式，不是四项已测出的可加“误差占比”。

## 3. 可检验的集合假设

固定同一状态及同一联合主体 raw 预测 q。S 为该次 raw logits 的 Top256，U 为其补集。p 为同 H 下 target 实际归一化分布，r 为实际修复后分布。

若仅对 S 的 logits 施加残差，最后做同温度完整 softmax，且没有改变支持的过滤/额外处理，则：

\[
r(v)=c q(v)\quad(v\in U),\qquad r(\cdot\mid U)=q(\cdot\mid U).
\]

即尾部总质量可以随归一化改变，尾部内部的条件比例不变。定义允许候选内任意修正的放宽集合闭包：

\[
\mathcal F_S(q)=\{r\in\Delta_V:\ r(v)=c q(v),\ v\in U,\ c\ge0\}.
\]

有限 logit、rank512、剂量上限及跨状态共享参数使真实头的可达范围通常更小。\(\mathcal F_S\) 的 oracle 是放宽上限，不是当前头已经能学会的最优方案。

实施前按实际采样阶段核验：温度相同、top_p=1、top_k关闭、重复惩罚/支持 mask 等处理有明确身份；比较 r 与 q 的尾部条件分布并记录误差。S 来自同次联合 raw，不得混入独立主体的 S。过滤改变支持时不能直接套本集合。全词表温度校准通常也不属于该集合，不要求它满足这里的风险下限。

## 4. 放宽集合下的精确风险下限

当 q(U)>0 时：

\[
 D_S^*:=\inf_{r\in\mathcal F_S(q)}\mathrm{TV}(p,r)
 =p(U)\mathrm{TV}(p(\cdot\mid U),q(\cdot\mid U)).
\]

一个最优分布是 S 内 r*=p，U 内 r*(v)=p(U)q(v)/q(U)。证明：令 a=r(U)，尾部 L1 为 \(\|p_U-aq(\cdot\mid U)\|_1\)，候选内 L1 至少为 |a−p(U)|；三角不等式给出在 a=p(U) 时取得的下限。不需搜索 c。

同一放宽最优分布还给出 forward KL 下限：

\[
 \inf_{r\in\mathcal F_S(q)}\mathrm{KL}(p\|r)
 =p(U)\mathrm{KL}(p(\cdot\mid U)\|q(\cdot\mid U)).
\]

KL 由 S/U 分组的链式分解得到；不要把 KL 和 TV 的最优值或排序混用。p(U)=0 时两下限为0。q(U)=0 时集合只能保留尾部零质量，TV下限=p(U)，p(U)>0 时 KL 为无穷；若 U 内单个 q(v)=0 而 p(v)>0，KL亦为无穷。实际 full-softmax 的数值下溢不能伪装成理论零支持；用 logsumexp/稳定计算并记录精度。

令 \(D=TV(p,q),\ D_h=TV(p,r),\ A=D-D_S^*,\ \Delta=D-D_h\)，则：

\[
A\ge0,\quad D_h-D_S^*\ge0,\quad\Delta\le A.
\]

A 是“放宽集合允许的最大 TV 改善”；D_h−D*_S 是“实际头距放宽 oracle 的差距”。后者混有真实表达约束和学习因素，不能全称为尚可学会的空间；它等于 A−Δ，不是新的独立机制证据。所有量都需要当前 target p，是离线解释量。

CPU 反例：S={1}，p=(.60,.20,.20)。q_A=(.78,.11,.11) 与 q_B=(.60,.38,.02) 的 raw TV 都为 .18，且 S 均为 raw Top1；前者 D*_S=0，后者 D*_S=.18。相同误差大小可以对应不同的放宽修复空间。这是说明研究问题的标准数学例子，不是 E2 实验证据或新定理声称。

## 5. 新实验到底检验什么

### H_R：尾部条件形状是否带来增量解释

对同主体、同 C/H/i 采集至少这些标量：D、D_h、D*_S、p(S)、q(S)、r(S)、position、domain、raw熵；另存候选内/尾部的实际 TV 改善，两者之和必须为 Δ。与上轮相同的前驱置换可作次要对照，但不重新执行上轮已完成的主检验。

只拟合两套同类低容量离线回归器：

- M0：原始 TV、位置、领域、p(S)、q(S)。在 dev 上预先固定是否加入 D²、p(S)²、D×p(S) 等少量非线性项。
- M1：相同特征/拟合流程，只增加 D*_S。不要同时加入 A、D*_S、D_h 或 Δ；加入 D_h/Δ 是直接泄漏结果。

建议固定 ridge，正则在 dev 按 prompt 分组交叉验证，网格 {0.01,0.1,1,10,100}；标准化参数仅取 dev，两模型使用相同 folds/权重。特征维度≤32、参数<10,000。每个 prompt 总训练权重相同，不能让长回答主导。固定模型/系数后只打开新 test 一次。

**主要判据：** 使用 i=2…15，对真实 Δ 的逐状态预测误差先按 branch→position→C→prompt 汇总MSE，再比较 M0−M1 的配对损失差及 prompt bootstrap 区间；首位置另报负对照，不混进主要指标。给每域值、实际 Δ、残差图和边界距离分布。基线须包含覆盖率，防止把“覆盖率本来已解释”误称新几何发现。

给定 D，A 与 D*_S 信息等价；但标准化/正则惩罚下的ridge数值拟合未必等价，实施时固定只加D*_S，不互换选更好的版本。特征与 Δ 共用 p，留出只防拟合泄漏，不消除数学依赖或建立因果关系。最多支持“尾部条件形状提供额外离线解释”，不能说头显式感知该 oracle、出现可部署路由器或发现唯一原因。仅验证 Δ≤A、报告 A 与 Δ 相关，均不算 H_R 的经验支持。

### H_N：局部修复能否迁移到 native 状态，以及接受后果

H_N的**主要局部迁移指标**是native B2实际reached、i=2…15状态上的 shadow raw−actual repair TV，即平均Δ_N。每请求先等权平均符合条件的状态，再prompt/域等权；没有合格状态的请求记缺失与覆盖，不填0，整请求计数仍保留。正值及其区间只支持局部改善迁移。

B0/B1/B2 各自真实生成并计数，不能把三臂当同 token 轨迹。B2−B1的“每请求已接受proposal数/实际proposal验证轮数”是预定关键后果指标；实际输出/全部调度轮数为辅助后果。两者各自先在完整请求计算再prompt配对比较，报告不确定性。**只有Δ_N为正，不能写已建立接受收益迁移；后果指标还须同向并有相应统计支持。** 局部为正而接受后果不明确时，结论必须是“局部迁移得到支持，接受后果仍不确定”。分母为0时记缺失，完整请求仍计入覆盖/失败统计，不因科学效果删除请求。

桥接成功只是测量前提；概率加权存活与随机实际接受的一致性是统计检查，不要求逐轮相等。期望需用实际 Q 上的 G_k∏b_i，G 不能包含已实现接受事件；EOS、bonus、correction、零输出轮分别记账。

可在锁前决定将 HF dev 的 M0/M1原样用于 native reached，作为预定跨测度验证，不在 native test 重拟合。不要把 HF 与 native 状态合并做单一指标。若没有建立实际分布身份，H_N 保持不确定。

### 可选 H_V：是否存在推理可见的收益预测信号

仅在核心完成且预算允许时进行，锁前决定是否执行。使用≤8个不依赖 target 的特征（例如位置、raw熵/top1差、q(S)、前驱特征、既有剂量），预测 Δ 或其符号；用同样的 dev 分组和新 test。若使用修复后 q 的特征，明确必须先支付头成本，不能宣传为省掉头计算的门控。此轮不接入服务、不训练新头、不根据旧12.7%状态拟合oracle gate。未做就不作可预测部署主张。

## 6. 支持、反证和退出

| 观察 | 允许的结论/动作 |
|---|---|
| M1 在新留出稳定胜 M0，且原始 Δ/域差异明确 | 支持限定测度中的增量离线解释；不等于新理论首创或因果机制 |
| D*_S几乎为0/与覆盖共线，或M1不胜M0 | 收缩几何解释；不扩大样本/换分层直到显著 |
| A大而实际Δ小或负 | 有放宽空间，当前头未实现；不凭oracle宣布方法有效 |
| 实际头风险低于D*_S超过数值容差 | 集合/支持/概率/实现假设有误，停止相应理论解释，不写“突破下限” |
| 校准风险低于D*_S | 校准通常不在集合内；不能据此认定下限错误 |
| HF解释成立、native不迁移 | 限制部署主张；保留测度差异，不能合并掩盖 |
| native只完成启动/anchor，未完成验证和计数 | 技术不完整，不是科学反证 |
