# Argument map

张力：已有低成本修复有效，但机制研究尚未区分具体误差来源及其适用条件。进一步求共同修正上限不能自动填补此缺口。

本轮问题：当前E2实际错误中，是否有“明确条件→特定近似环节→稳定错误形式”的候选，既有可追溯现象，也能设计出区分至少两种来源的检验？

不预设科学阳性。预期产物是最多一个小切口的受控检验卡，或“没有候选通过”的有依据结论。

链条：既有证据及负结果→无头成败筛选的raw错误图谱→最多3个候选及已知解释→每候选最多2个已存数据诊断→一个最小受控检验的设计与否定条件。

固定图谱：R8原fresh_test全部36题/69C、P/D/F eval、位置1/2/3/8/15、D/J；只用有完整target行的合法记录。统计raw与target的top1一致、概率质量配置、位置差异；同C/i/source的argmax频数与target平均概率区别只是监督竞争解释诊断，不是训练因果。

基础字段固定为TV、p/q top1及对应概率、p/q前二概率差、p/q熵(nats)、p在rawTop16/256的质量；只按source/body/position及top1一致与否输出预定表。还报每组top1一致/不一致对总体TV的贡献权重，避免只看子组均值。监督图为同C/i/source的m=均值p与v=argmax频数：TV(m,v)、TV(q,m)、TV(q,v)，不称m为TV最优，也不假设D-PACE加权CE的最优是v。第一位置单一H的m/v差异是硬化的数学结果，不能当发现。

诊断计数边界：同一候选换阈值、筛域、换主指标或加交互项属于新增分析版本，不能藏在一次诊断里。合同冻结后不优化这些选择；技术修复保留前后代码与原因。最多3候选、每个D1+D2共2诊断，图谱之外最多6项。既有报告已回答的诊断直接引用，不重算充数；缺字段则NA，不用另一个指标替代原问题。

执行可行性：旧资产只读，不复制大npz；每次处理一个C，target按小批次解码为FP64，禁止持有全库概率。预选按group_sha256排序首个有C1的题做吞吐/RSS计时，不据数值效果选择。完整扫描工时预测必须留预算给诊断、文献及收尾，超预算则优化读取/复用已有标量，不能改科学面板；仍不可完成则partial，输出具体缺口，不自动改做容易得到结论的子集。

执行契约补充：p=target(C,H)，q=D/J(C,i)；BF16位模式经FP32解码、FP64全词表softmax。top1与TopK并列按token ID升序，margin为前二概率差，熵为nats，覆盖为sum_{v in TopK(q)}p(v)。每格单列expected/valid/invalid/NA及题/C/槽/独特H分母，不按reached/accept筛选。自然EOS位置合法则保留，EOS后无效记录不补。监督图的TV(q,平均p)不等于平均TV(q,p)。原头固定附表仅用同C的F-source eval记录及其F_head_row连接q_J/q_F/p，不能跨来源按slot配对。

性能门禁另包含按元数据选定的最高唯一target行数C（并列按group_sha256、anchor排序）；共至多两个C，跑完整基础指标及F连接标量提取，F结果封存至最终选点封存后。按唯一target/head行与实际文件字节外推，包含候选诊断和收尾余量。仍无法满足预算时partial_resource_limited，未测候选不是已否定候选。NPZ不当作可按行mmap；禁止复制约8.76GiB全档突破8GiB新增预算。

D1/D2完成且最终选点封存后，另看F-source上原头是否改变预先定义的错误；这是相关性和方法连接，不因其阳性升级来源判断。禁止原头坏状态筛选、指标预测器、重新求oracle、增加历史长度。

计数明确：基础图谱、监督图及一张原头连接表是三项固定分析；另允许最多6项候选D1/D2诊断。连接表仅报冻结场景内外的TV前后差、损伤率及覆盖，沿用场景定义，无新阈值、机制指标或搜索。它不充当来源D2，也不能用于重选候选；资源预算覆盖三项固定分析和最多6项诊断。

每张候选卡必须分别填写：①只用raw/target/条件定义的可计算场景；②带方向的具体错误形式；③源码或原文可定位的近似环节；④至少两个竞争来源；⑤一个必要预测和一个两来源预测不同的观测；⑥哪些已存字段能测、哪些不能；⑦正/负/无法区分时分别改变什么结论；⑧即使原头无收益，这个问题是否仍成立。条件不许含原头成败或修复后数据；不能以“位置越后越差”直接推出原因。

每候选最多两项诊断，先保存诊断合同，再读取新增诊断结果：D1检查必要现象，D2检查竞争解释的不同预测。如果档案只能做D1，明确降级为“现象候选、来源未区分”，不发明第三个相关性指标补因果。所有旧数据已暴露，合同是防随结果改口，不是新鲜确认。

固定汇总：每个source/body/position分别计算；C内保留自然槽频数，题内对有效C等权，域内题等权；总体域等权。同步报独特H计数和等H敏感性，不能把独特H或69C当独立题。每候选给出每题方向、覆盖、负例与NA。作为跨域主候选的操作门槛：至少两域各有4题满足冻结条件；在这两域分别至少2/3有定义题满足预定方向。该门槛仅作本次筛选，不是统计确认；不够则局部线索，不补题、不改阈值。分母包括所有满足条件且有定义题，不删负例。

结论标签区分：必要预测不成立（只否定该预测在该面板的版本）；已知解释可覆盖其创新主张（不证明这个解释是当前模型原因）；数据不能区分（缺指定干预/字段）；局部线索；可进入受控检验。不能把后四者都写成科学反证。

反论点：这些结果可能被已有条件恢复、校准、监督或优化解释覆盖。文献已有某机制时，淘汰其“新机制”主张，但保留它作为需要验证的竞争解释；若本地出现新的具体适用条件/失败规律，必须写明增量认识再比较。不能将“未找到同名论文”作为新颖性证据。

源机制确认可能需要同信息、同监督、同预算的训练干预。本包不假装旧概率能代替它：最终写出可执行的下一次小型受控检验，但不实施未授权训练、不自动下一轮。


终审补充：D1须可能在满足场景定义时失败；定义恒真不是支持证据。最终选点含零候选决定先签名为FINAL_SELECTION，随后解封C，C不得改变选择。
