# 核心问题审核

结论：**通过，范围限于具体机制候选的发现、淘汰和下一次受控检验的选择。** 它不保证找到新机制，也不承诺旧概率档案能确认训练、模型规模或表示来源。当前交付是执行包，尚未启动科学分析。

依据仓库AGENTS及用户最新要求，检查的是能否从一般模型差距收缩到一个具体、可否定的小问题。

| 检查项 | 本包的直接对应 | 不能越过的边界 |
|---|---|---|
| 失配形成 | 场景—错误方向—具体近似环节；D1必要预测、D2竞争预测 | 只有描述图或头收益时不能宣称识别原因 |
| 什么能修、为什么 | 先引用R1–R9已有可修性证据；新候选须说明特定来源如何产生可修错误，最终受控卡改变该来源因素 | 不再求一个平均有益探针当答案；方法连接表不替代来源检验 |
| 何时失败 | 必要预测可失败、负例/NA全保留；明确不可区分与反证 | 方法失败不等于失配不可修；缺干预不等于候选为假 |
| 怎样指导方法 | 机制候选独立于头成败选择，检验卡先固定要改变的原因因素 | 未确认前不预设新架构，不因模型有效保证理论创新 |
| 避免已知问题改名 | 近邻原文矩阵，既有机制或新适用边界分别定位 | “决策/系统性/输出适配”名称自身不构成小切口 |
| 有效判断 | 五类结论、跨域操作门槛、0候选允许完成 | 不无论结果如何都宣布支持；不把操作门槛当统计确认 |

## 仍可能发生的阴性结果

完整扫描可能只发现已知问题，或所有具体来源都需要新干预才能区分。此时执行chat应交付负结果或不可识别判断及明确缺口，不能继续换名、加指标、追加候选。只要规定工作完成，零候选是有效完成；必要工作没完成则partial。
