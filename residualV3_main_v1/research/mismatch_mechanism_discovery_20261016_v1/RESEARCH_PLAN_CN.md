# 研究计划：从错误现象走向具体来源

## 这次究竟要解决什么

用户要的是像“块内实际条件缺失”那样具体、可检验的问题。当前缺口是：**已经知道模型可以改善，但还不知道原始草稿在什么条件下，因哪个具体近似而犯了可修复的错。**

本轮不提前写论文结论。完成标准是用数据和文献选择一个值得直接验证的来源假说，或有依据地说明目前没有这样的候选。选择假说与证明假说分开。

合格的问题句式为：

> 在【可计算场景】下，【某个源码/原文可定位的近似】可能导致【带方向的具体错误】；若该解释成立，应观察到【必要预测】，而【竞争解释】对【指定比较】有不同预测。

“大小模型不协同”“决策 mismatch”“系统性 mismatch”“输出不适配”单独都不合格。名称必须落到可测的错误和能被否定的解释。

## 已有证据怎样使用

| 已有结果 | 本轮能据此做什么 | 不能推出什么 |
|---|---|---|
| R1正确前驱比置乱更有效；单温度无法复现完整收益；首位置收益近零 | 将条件恢复、较丰富的校准列为竞争解释，保留首位置控制 | 剩余收益就是“系统性成分”；所有位置存在相同读出缺陷 |
| R2收益主要落在原Top256坐标；几何指标增量未确认 | 检查候选内概率分配及候选覆盖的区别 | 候选覆盖就等于理解正确；hidden已含充分信息 |
| R3统一半剂量整体更差；R6新增历史预测未确认 | 不再用统一过量、更多历史预测解释全部失败 | 所有损伤都不可避免 |
| R5–R8共同探针有效，跨历史来源仍有损伤 | 支持存在可重复修正机会 | 已识别偏差形成原因，或探针可部署 |
| R9共同安全余量与高收益取舍并存 | 约束共享预测的可修范围 | 当前原头损伤均由信息不足造成 |
| raw训练与repair训练的监督不同 | 把监督差异放进解释竞争；核对源码 | 硬标签已被证明是当前失配主因 |

各轮面板、轨迹及口径不同，不能拼接为独立成分的收益百分比。原native概率警报保留；本轮不研究runtime无偏性。

## 三项固定分析

**A. 原始错误图谱。** 在完整旧面板中区分 top1一致但概率分配不同、top1不一致、target概率质量落在草稿候选之外等可观测情况。它们是错误形式，不自动成为原因。报告频率、每题分布和对总体TV的加权贡献，避免用少数异常代替整体。

**B. 监督竞争解释的描述性检查。** 同C、同位置、同来源中，比较target平均概率与target首选token的频数分布，以及raw分别靠近哪一个。实际训练源码采用硬/软不同监督，因而这个检查有来源依据；但存档采样频数不是实际训练标签分布，不能据此认定训练因果。

**C. 原头连接附表。** D1/D2完成并封存最终选点或零候选决定后，仅在F来源同状态上比较J raw与原头TV、损伤率。它回答“这个候选现象是否与现有方法相关”，不能回答“方法为何有效”，也不能用它反向挑候选。没有方法关联就报告该缺口，不能换选另一个候选。

精确指标、权重、分母见[执行指南](EXECUTION_GUIDE_CN.md)。A/B完成后才生成候选；C的结果在候选冻结前不读取。

## 候选怎样产生、怎样淘汰

最多3个候选，从A/B和原论文证据中产生，不预先分配“一个监督、一个输出、一个历史”的名额。每个候选填写[完整合同](protocol/CANDIDATE_TEMPLATE_CN.md)，然后冻结两项诊断：D1检查必要现象，D2检查竞争解释预测不同的地方。

D1必须可能在满足场景定义的样本上失败；由筛选条件或概率恒等式保证的结果仅作描述，不能当支持来源候选的证据。

允许发现阶段使用已暴露数据形成假说；必须记录先后访问。冻结不使这些数据重新成为新留出。若需要同信息、同预算的训练干预才能区分来源，D2必须写“当前不可测”，不能换成相关性图宣布确认。

| 结果标签 | 判断及下一步 |
|---|---|
| 必要预测未观察到 | 该面板上的候选版本失去支持；保留全部负例，不换阈值救结果 |
| 已有工作覆盖创新主张 | 淘汰重复的新颖性表述；保留该机制作为竞争解释，不宣称已识别本项目原因 |
| 数据不能区分 | 指明缺哪个字段或干预；不当作反证，也不当作支持 |
| 局部线索 | 只在少数题/一域出现，记录范围，不扩成普遍机制 |
| 可进入受控检验 | 现象有覆盖、预测可否定、近邻差异具体、干预能区分来源；仍是待验证假说 |

跨域主候选的操作门槛：至少两域各有≥4题满足冻结条件且有定义；这两域各自≥2/3有定义题符合冻结方向。未满足仅记局部线索，不补题。该门槛用于限定探索选择，不是显著性或一般性证明。真实负例和所有NA分母都保留。

最多6项D1/D2；改阈值、改场景、筛域、换主指标或加交互均是新增版本，不能隐藏在一次诊断中。重复使用A/B已经给出的结果可直接引用，不必另算。不得以“没有找到同名论文”判断创新。

## 最后怎样选一个点

先排除无可测场景、无竞争预测、纯重命名、只有原头相关性的候选。剩余候选按以下顺序审查：来源可区分程度、每题/跨域覆盖、近邻工作之外的具体增量认识、最小受控检验的可行性。并列时保留更小的主张及更少混杂的检验，写出选择理由，不制定看似精确的综合分数。

可以保留“已有机制在一个未说明条件下失效”的切口，前提是找到具体新条件和可检验预测。机制完全已知且适用边界也已覆盖，则不继续包装创新。

选中者须交一张后续受控检验卡：实验单位、唯一改变的来源因素、保持相同的信息/数据/监督/参数或计算预算、唯一主终点、最小可区分效应、反证条件、资源估计及尚缺资产。预算匹配无法做到时写混杂，不声称干预纯净。该卡不在本包执行。

**收尾判断必须落在“具体问题是否找到了、证据是哪一条、来源还缺哪项直接检验”。** 不再以完成多少轮、多少审计或平均改善代替这个判断。
